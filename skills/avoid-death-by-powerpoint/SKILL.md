# Avoid Death by PowerPoint

Apply these five principles to every slide.

## 1. One message per slide

- Each slide communicates one clear idea or takeaway.
- Split slides containing multiple independent concepts.
- Remove content that does not support the slide's single message.

## 2. Protect working memory

- Audiences cannot read long text and listen to a speaker effectively at the same time.
- Eliminate sentences and paragraphs from slides where possible.
- Prefer short text fragments, impactful images, and simple visuals.
- Keep bullets to an absolute minimum.
- Treat slides as visual aids, not speaker scripts.

## 3. Make size establish hierarchy

- The brain naturally focuses on what is largest.
- Make the most important element the largest element.
- Do not automatically make the title or header largest; enlarge it only when it is the most important message.
- Make core data, images, or keywords large when they carry the main point.

## 4. Use contrast to control focus

- Use contrast to direct attention to the intended focal point.
- Use dark backgrounds and bright, contrasting accent colors when appropriate.
- Keep secondary content less visually dominant.
- Remember: the speaker is the presentation; slides are visual aids.
- Never sacrifice legibility or accessibility for contrast. Do not communicate meaning through color alone.

## 5. Apply the Rule of Six

- Keep visual objects—text boxes, images, shapes, charts, and similar elements—to six or fewer per slide.
- Remove clutter when a slide exceeds six objects.
- Do not force six objects when fewer communicate the message better.

## Agent workflow

When reviewing, formatting, or generating a deck:

1. Analyze each slide against all five principles.
2. Identify violations: multiple messages, excessive text, weak size hierarchy, unfocused contrast, or more than six objects.
3. Critique the violations briefly.
4. Refine by splitting slides, shortening text, changing visual size, strengthening focus, and removing clutter.
5. For each suggested slide, provide:
   - **Text**
   - **Visual/Image**
   - **Size hierarchy**
   - **Speaker notes**
6. Remind the user: **“You are the presentation. PowerPoint is merely your visual aid.”**

## Output standard

- Preserve the user's meaning and facts.
- Do not add decorative elements without a communication purpose.
- Prefer fewer elements when fewer are sufficient.
- Keep speaker notes separate from slide text.
