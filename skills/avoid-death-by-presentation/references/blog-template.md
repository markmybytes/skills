# Blog Template

Fill this shape with the user's content, voice, and language. The structure comes from a working example; the annotations explain why each slot exists so you can deviate deliberately, never accidentally.

---

```md
# [Title]

**[One-line hook — the angle, stakes, or promise]**

[INTRO — 1-2 short paragraphs. Earn attention with a scene, a contrast, or a stake. Establish why this matters to the reader. Never summarize the post; start the post.]

---

## [Section 1 header — names the idea, not the topic]

[Prose with a mini-arc: problem → substance → stakes. A reader who stops here should still leave with something.]

### [Optional sub-section — when a section needs internal structure]

[Use for parallel facets of one section. Keep them shallow: `###` is the floor for nesting; deeper levels mean the section is doing too much.]

## [Section 2 header]

[Prose. Escalate: deepen the idea, add history or mechanism, or complicate it. Bullets ONLY for genuinely enumerable items — each bullet gets a bold lead-in plus explanation.]

## [Section N header — usually the payoff]

[Turn the idea back onto the reader: how to apply it, what changes for them, or the point the whole post was building toward.]

[OPTIONAL CLOSER — one or two lines. Callback, joke, or landed point. Personality welcome; forced inspiration is not.]
```

---

## Slot rules

- **Title:** specific over clever. Name the subject; let the hook carry the selling.
- **Hook line:** one sentence. If it takes two, the angle is not sharp enough yet.
- **Sections:** each has ONE job and its own arc. `##` headers that name ideas (not generic labels like "Background"). A reader should be able to enter at any section.
- **Sub-sections:** `###` is allowed inside a section for parallel facets. Shallow only — if a section needs `####`, split the section instead.
- **Bullets:** prose-forward by default. Bullets are for things that are genuinely a list of parallel items — not a shortcut for unfinished thinking.
- **Density:** compact. Cut anything that serves no section's job, however interesting.
- **Voice:** the user's language, register, and humor, where their material shows it. Match their voice, not this template's tone.
