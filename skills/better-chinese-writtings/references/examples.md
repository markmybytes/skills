# 中文用字與寫作指南：實例

本文件示範如何辨識並刪減不必要的歐化中文與翻譯腔，協助使用《中文用字與寫作指南：更精簡、更流暢》修訂文稿。

例句是診斷參考，不是禁詞表；去除歐化句式時，優先考慮準確、約定俗成的中文動詞、熟語、成語與四字格，以壓縮冗長表達、改善節奏；不得為求古雅而硬塞、堆疊或改變原意。

## 1. 弱動詞＋抽象名詞

| 原句 | 建議 | 理由與例外 |
| :--- | :--- | :--- |
| 我們正在進行彩排。 | 我們正彩排。 | 「進行＋名詞化動詞」多為冗贅；「會議正在進行」中的「進行」是實義動詞，保留。 |
| 他作出了說明。 | 他說明了。 | 「作出」無實義；公文「作出裁決」合體例，可保留。 |
| 公司將予以處理。 | 公司會處理。 | 普通文書更簡潔；正式公告的「予以」是禮貌套語，可留。 |
| 雙方就此事進行了磋商。 | 雙方磋商此事。 | 新聞導語若需動賓齊整，原句無害；其餘場合可簡。 |

## 2. 冗餘介詞與連接詞

| 原句 | 建議 | 理由與例外 |
| :--- | :--- | :--- |
| 當我看見他時，我感到很高興。 | 我看見他，很高興。 | 「當……時」常可省，時間由上下文可知。 |
| 關於這個問題，我們需要討論。 | 這個問題，我們需要討論。 | 話題可直陳；學術論文的「關於」開頭合體例。 |
| 透過這個計畫，學生得以接觸業界。 | 藉此計畫，學生得以接觸業界。 | 「透過」是常見翻譯腔，但不算錯；「藉此」更簡。 |
| 由於下雨的關係，比賽延期了。 | 因下雨，比賽延期。 | 「由於……的關係」疊床架屋；口語「因為下雨」亦自然。 |

## 3. 長定語與資訊順序

| 原句 | 建議 | 理由與例外 |
| :--- | :--- | :--- |
| 那個昨天在會議上提出了一套非常複雜的改革方案的同事，今天辭職了。 | 昨天會議上，有位同事提出了一套很複雜的改革方案；他今天辭職了。 | 長定語前置難讀；拆句並按「先背景、後主語」重排。 |
| 本公司生產的、專為戶外活動設計的防水手錶深受歡迎。 | 本公司生產的防水手錶專為戶外活動設計，深受歡迎。 | 雙重定語拆為兩個分句；科技專利中的長定語術語不宜硬拆。 |
| 這個被多次修改的、內容冗長的合約條款，我們需要處理。 | 這份合約條款被改過多次，內容冗長，需要處理。 | 拆長定語；保留「被修改」的承受義與「需要處理」的對象。 |

## 4. 被動語態

| 原句 | 建議 | 理由與例外 |
| :--- | :--- | :--- |
| 車門將被打開。 | 左側車門即將開啟。 | 車廂廣播意在告知車門方向與時間；不要改成「請下車」一類指令——那會改變語意。 |
| 這個建議被人們廣泛接受。 | 這個建議廣獲接受。 | 「被人們」贅餘；「獲」已含承受義。 |
| 他被老闆辭退了。 | 原句保留。 | 「被」表不如意遭遇，是正常用法；不必為避「被」而改主動句。 |
| 太陽被烏雲遮住了。 | 原句保留。 | 描述自然現象，「被」自然順口；改「烏雲遮住了太陽」亦好，兩可。 |

## 5. 直譯與英文資訊結構

| 原句 | 建議 | 理由與例外 |
| :--- | :--- | :--- |
| 向毒品說不！ | 拒絕毒品。／遠離毒品。 | 「Say no to…」套譯；口語廣告用原句亦可。 |
| 我們準備好了。 | 一切就緒。 | 「準備好了」不是錯，日常口語完全正常；正式場合求簡雅可用成句。 |
| 香港常被稱為「購物天堂」。 | 香港素有「購物天堂」之譽。 | 「被稱為」直譯 be called；「素有……之譽」更簡雅。 |
| 我們為夢想創造可能。 | 我們助人圓夢。 | 「創造可能」是宣傳套語；若原文刻意抽象，保留亦可。 |

## 6. 官腔與空泛措辭（技術用語除外）

| 原句 | 建議 | 理由與例外 |
| :--- | :--- | :--- |
| 存在著許多困難。 | 有許多困難。 | 「存在著」常為填充詞；哲學、數學語境中的「存在」是術語，保留。 |
| 落實各項工作。 | 執行各項計畫。 | 行政慣用語；法規中「落實法律規定」是術語義，保留。 |
| 優化用戶體驗。 | 改善用戶體驗。 | 例示性：此處「優化」缺乏具體所指，換「改善」更實在；若語境清楚（如技術性能調整），保留「優化」亦可，判斷依語境而定。 |
| 打造城市品牌。 | 建立城市品牌。 | 例示性：「打造城市品牌」所指較泛，「建立／塑造」更直接；若語境已給出明確動作，保留「打造」亦可。 |
| 本書語言高度濃縮。 | 本書語言凝練。 | 形容文字密度，「凝練」更貼切；「濃縮」用於果汁、精華等是正常詞彙。 |
| 辦事有效率。 | 原句保留。 | 「效率」是普通詞彙，不是物理術語誤用；「快捷、迅速」是另一種說法，非唯一正解。 |

## 7. 文言傾向簡潔詞彙（不過度）

| 原句 | 建議 | 理由與例外 |
| :--- | :--- | :--- |
| 當局表示，之後將公布詳情。 | 當局表示，其後將公布詳情。 | 「其後」略雅；口語中「之後」正常。 |
| 如果你方便的話，請回覆。 | 如方便，請回覆。 | 「如果……的話」口語化；書面可省。 |
| 雖然他年紀輕，但是經驗豐富。 | 他年紀雖輕，經驗卻豐富。 | 更緊湊；原句亦無錯。 |
| 很顯然，此路不通。 | 顯而易見，此路不通。 | 成句更穩；日常口語「很顯然」無害。 |

**尺度**：文言化是選項，不是義務。每處改動須比原句更簡潔或更精確，否則不動；不把「但是」一律改「惟」，不為求古而用僻字。

## 8. 領域術語保護

| 原句 | 建議 | 理由與例外 |
| :--- | :--- | :--- |
| 當事人須依法律程序提起訴訟。 | 原句保留。 | 「法律程序」是法律術語，不可改「步驟／手續」。 |
| 系統啟動時將載入配置。 | 原句保留。 | 「啟動、載入、配置」是技術術語。 |
| 醫生建議完成整個療程。 | 原句保留。 | 「療程」是醫學術語，不可換為「過程」。 |
| 投資者應評估市場變數。 | 原句保留。 | 投資語境中「變數」是正常詞彙，不是數學術語誤用；想更簡可寫「市場變化」。 |

## 9. 標點、格式與輸出保留

| 原句 | 建議 | 理由與例外 |
| :--- | :--- | :--- |
| 他說：「這件事，我們明天再談。」 | 原句保留。 | 全形引號與標點按原文，不擅自改為西式標點。 |
| 程式碼 `if (x > 0) { run(); }` | 原句保留。 | 程式碼、變數名、字串一字不動。 |
| 支援 5G 與 Wi-Fi 6。 | 原句保留。 | 技術名稱、字母與數字照原樣。 |
| Markdown 表格、連結、編號清單 | 原句保留。 | 潤飾文字不破壞格式結構；未要求時不加粗、不加修改標記。 |

## 10. 負面例子：原句應保留

| 原句 | 是否改動 | 理由 |
| :--- | :--- | :--- |
| 我很欣賞你的服務。 | 保留；至多改「我很欣賞你的服務態度」。 | 「欣賞」是正常用法；不要改「謝謝」——那會把讚美改為感謝。 |
| 此舉造成寒蟬效應。 | 保留。 | 要表達的就是 chilling effect 這個概念；改「噤若寒蟬」反而改變語意（那形容人不敢出聲，不是現象本身）。 |
| 當事人須依法律程序提起訴訟。 | 保留。 | 法律術語與條文語體。 |
| 我期待你的來信。 | 保留。 | 「期待」是標準詞；不必改「盼望」，除非用戶要求更古雅的語氣。 |
| 合約載明雙方權利義務。 | 保留。 | 合約語體與術語，一字不動。 |

## 11. 成語與四字格（條件式運用）

成語／四字格可壓縮重複或冗長措辭、改善節奏，但改善的是**簡潔與節奏**，不自動代表更精確——精確靠字面義與語境。判斷基準：含義、語氣、地域、受眾是否都吻合。不強推、不疊用、不用生僻或來路不明的成語、不為遷就成語而改變技術或法律含義。

| 原句 | 建議 | 理由與例外 |
| :--- | :--- | :--- |
| 事前做好準備，以防意外。 | 未雨綢繆。 | 語境相合時可濃縮鋪陳、收緊節奏；口語或需說明因果的場合，保留原句亦可。 |
| 事情失敗後才設法補救。 | 亡羊補牢。 | 含義相符、要點在「事後補救」時可用；需精確描述時序或具體步驟時，保留原句。 |
| 大家同心協力。 | 同心協力。 | 「同心」已含「大家」之義，省去重複；「同心協力」亦常接動詞短語，兩者皆通。 |
| 改善系統性能。 | 原句保留，不改「精益求精」。 | 「精益求精」指不斷追求更完美，與「改善性能」的技術含義不對等；技術語境改四字格反而失準。 |
| 當事人須依法律程序提起訴訟。 | 原句保留。 | 「法律程序」是法律術語，不可為求雅改為其他四字格。 |
| 我很期待結果。 | 原句保留。 | 「期待」是正常詞彙；「望穿秋水」語氣過重、不合語境，不必勉強用成語。 |

**尺度**：四字格是濃縮手段，不是裝飾。用之前先問：含義、語氣、地域、受眾都吻合嗎？比原句更簡潔或更有節奏嗎？任何一項不滿足，保留原句。

## 交稿前快速檢查

1. 原意、事實、數字、專名、情態是否無損？
2. 術語與法律／醫學／技術含義是否未動？
3. 改動只是風格取捨，不是對錯判斷？
4. 有沒有把讚美改感謝、概念改狀態、中性改立場？
5. 刪字前先問：這字在原語境站得住嗎？站得住就還原。
6. 地域含糊時是否先問、或已最少說明？
7. 格式（Markdown、程式碼、表格、引號）是否完好？

**最後**：以上全是條件式啟發，不是黑名單。同一句式在不同語體中的判斷不同；判斷依據是「意思不變、讀者讀得順、不丟原意」，不是詞彙的來源或新舊。
