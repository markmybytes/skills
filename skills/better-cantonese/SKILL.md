# 香港中文書面語潤稿指南

目標：自然、清楚、精確。基準：香港常用繁體書面語。
三類問題：歐化翻譯腔、病句、官腔空話。

## 基本立場

- 授權大改：重組、換語序、拆長句、補成分、理段落，全部合法。
  只改錯字=未完成。
- 原意神聖：事實、數字、日期、承諾強度、術語、語氣、立場、格式不變。
  拿唔準：提問，不臆測。
- 語理優先：句子邏輯唔通，換走幾多詞彙都係唔通。
  遇到語理罅隙（關係冇交代、因果斷纜、歧義拿唔準）——
  照交你理解嘅最合理修訂，再用一句講出理解、確認方向：
  「我理解為 X；如果你想表達嘅係 Y，話我知。」
  唔好靜靜保留有問題嘅句；用戶要求「只回傳修訂稿」時省略這句，
  自己揀最合理讀法。
- 模式=提示，唔係禁詞表。
  每個模式只提醒檢查：是否遮蔽意思、拖慢節奏、造成歧義。
  良性用法（「被老闆辭退」「落實法律規定」）照保留。
  永遠標準：意思不變、資訊清楚、香港讀者讀得順。
- 香港書面語 ≠ 粵語口語轉錄。
  「唔、嘅、咗、喎」只用於用戶明確要求港式口語。
  香港慣用詞（屋苑、查詢、登記、質素、升降機）係正確用語，勿換其他地域寫法。
  字形：「著」（拿著、沿著、著想），唔用「着」。
- 輸出契約：預設只回修訂稿。
  未建立偏好 → 修訂稿後加非阻塞提示：
  「如需台灣、內地、澳門、新加坡、馬來西亞中文，或粵語口語/港式口語，可隨時指定。」
  用戶要求「只回傳修訂稿」「不要說明」或已指定偏好 → 省略。

先判斷再動筆：

- 法律、醫療、合約、學術 → 精確優先，固定結構不拆、模態詞不改。
- 對話、廣告、文學 → 保留口吻節奏，除非用戶要求統一。
- 引文、標語、代碼、URL、變數名 → 一字不動。
- 一般敘述、公告、報告、電郵 → 按目錄正常化。

## 診斷目錄 A：歐化句式（翻譯腔）

中文靠動詞推進，英文靠名詞虛詞搭建。
翻譯腔=拆走中文引擎，裝上英文車架。

### A1. 弱動詞+名詞化

「進行/作出/予以/加以/實施」+雙音節動詞，把動作降格成貨物。

- 我們正在進行彩排。→ 我們正在彩排。
- 警方進行調查，並作出拘捕。→ 警方調查並拘捕。
- 因應道路將會進行改善工程 → 因應道路改善工程。（「進行+自足名詞短語」直接用名詞；「改善工程」本身是名詞。）

**硬檢查**：刪弱動詞後，句子仍須像正常中文。「就全球化作匯報」不完整——

- 他就全球化作匯報。→ 他匯報全球化議題。/他以全球化為題作匯報。

同樣，「就此事作交代」應寫「交代事件經過」或「就此事作出交代」。
動詞必須自然帶上賓語，刪字不是機械操作。

### A2. 「的」字連環

三個以上「的」串長定語=英文關係子句直譯。中文後置說明或拆句。

- 他是一位有著極其豐富的實踐經驗的優秀的工程師。→ 他是經驗豐富的優秀工程師。
- 參差的斑駁的黑影投在長長的寂靜的街道上。→ 參差而斑駁的黑影，落在寂靜的長街上。

### A3. 大帽子句

長修飾塞名詞前=頭重腳輕。先主幹，後細節。

- 我見到一個長得像你兄弟說話也有點像他的陌生男人。
  → 我見到一個陌生男人，長得像你兄弟，說話也有點像他。
- 這個涉及開支約10億的建議可讓70萬人受惠。
  → 這個建議涉及開支約10億，可讓70萬人受惠。

### A4. 濫用「被」

中文「被」多含不如意、受損。
中性/正面事態套「被」=英文被動直譯；改主動、「獲/受/當選」或無主句。

- 曾先生如期被選為特首。→ 曾先生如期當選特首。
- 著名鋼琴家昨晚被邀請出席晚會。→ 著名鋼琴家昨晚獲邀出席晚會。
- 相關請求將會被系統拒絕。→ 系統將拒絕相關請求。

告示要點是系統做什麼；主動更短。
轉主動時可順手把「相關/有關」泛稱還原為具體所指（原意內含時）：系統將拒絕舊版請求。
但「被老闆辭退」「太陽被烏雲遮住」係正常中文，勿為避「被」而改。

### A5. 濫用「一個」

英文有冠詞，中文冇。

- 是一個小五學生 → 是小五學生

### A6. 萬能連詞

英文 and 見列舉必插；中文並列靠語序自成節奏。
柴米油鹽醬醋茶不必「以及」，春夏秋冬不必「和」。
列舉刪連詞，更緊湊。

### A7. 代詞與所有格堆砌

中文承前省略係常態。

- 一個軍人應該隨時為他的祖國獻出生命 → 軍人當隨時為國家捐軀。
- 我買了它了，它非常好聽 → 買了，很好聽。

指涉可能混淆先補回代詞。

### A8. 「……之一」

one of the... 直譯，削弱判斷句。

- 名著之一 → 名著
- 最棘手的難題之一 → 極為棘手的難題

真係要列舉多個成員先用。

### A9. 介詞外框

關於、對於、在……上/方面、作為——英文介詞短語直譯，簡單主謂句變頭重腳輕。

- 關於他的申請，委員會今天進行了審查。→ 委員會今天審查了他的申請。
- 在環境保護的問題上，我們必須加強合作。→ 面對環境保護問題，我們必須加強合作。
- 對於這些不禮貌的行為，我不能不質疑。→ 這些不禮貌的行為，我不能不質疑。
- 由於他家境貧窮，他只好休學。→ 他家境貧窮，只好休學。

話題可作賓語直陳時刪框。「就」較輕，「對於」較重。
告示致歉句：「對於安排造成的不便，敬請體諒」
→「安排造成不便，敬請家長體諒」或「不便之處，敬請家長體諒」。

### A10. 「當……的時候」

余光中：「當當之聲不絕於耳」。時間關係清楚即刪。

- 當警報劃破寂靜夜空的時候，市民倉皇逃生。→ 警報驟響，市民倉皇逃生。

### A11. 「們」字成災

中文用「眾、群、諸」或集體名詞。

- 聽眾們、運動員們、各位先生們女士們 → 一律刪「們」
- 人們 → 大家/世人

### A12. 抽象名詞後綴

-ability/-ness 直譯。

- 可讀性非常高 → 引人入勝
- 侮辱性 → 極其無禮
- 知名度 → 聲名遠播

固定技術術語（硬度、黏度、濃度）保留。

### A13. 機械「地」

逢狀語加「地」=-ly 直譯。中文有現成疊字文言副詞。

- 她慢慢地走在林蔭小道上。→ 她徐徐漫步於林蔭小道上。

### A14. 模糊程度詞

「在一定程度上」「做出了一定的貢獻」=逃避判斷。
改實際程度：略微/顯著/頗有。

### A15. 時態硬譯

中文唔靠形態表時態。

- 正在進行著討論 → 正在討論
- 已經是完成了工作 → 已完成工作
- 他每天都做完了功課 → 他每天都做功課。（習慣性動作同完成態衝突）

但「已、曾、正、將、會」表達嘅時間承諾必須保留——
唔可以未來變現在、推測變確定。

### A16. 長句無逗點

中文靠逗號呼吸。
超長句先找主謂賓，按邏輯因果斷句，不新增資訊。

### A17. 存在句虛主詞

there be 句式直譯，「有……的原因/情況」托住空洞尾詞。重心移前。

- 這裏一定有她缺席的原因。→ 她缺席一定有原因。

## 診斷目錄 B：病句

### B1. 介詞吞主語

句首「通過/經過/在……下」+「使/讓」=主語封死在狀語。

- 通過這次培訓，使他的業務水準大幅提高。
  → 這次培訓使他的業務水準大幅提高。（或：通過培訓，他的業務水準大幅提高。）
- 在他的座位上放了旅行的照片。→ 他在座位上放了旅行的照片。（刪句首「在」，主語現身）

### B2. 暗中換主語

後半句施事已變，卻承前省略。

- 小張表現突出，安排他任副主任。
  → 小張表現突出，上級安排他任副主任。（或：……因而獲委任為副主任。）

### B3. 謂語殘缺（名詞當動詞）

- 我不能不疑問 → 我不能不質疑

名詞作謂語須換動詞。

### B4. 賓語殘缺

「便能明白學生」欠賓語：「明白學生的難處」或「體諒學生」。
補寫須在原意內，勿添新事實。

### B5. 同義重複

詞義已含再講一次：
成功當選、一切任何、大約……左右、目前的當務之急、親自示範、預先安排、徹底根治、虛假失實。
刪一半。

- 聽到琴聲，感到十分感動 → 十分感動。（「感到/覺得」配自足情感詞冗餘；
  但「感到失望、感到自豪」自然，「感到」唔係禁詞。）
- 偵測到異常情況時 → 偵測到異常時。（填充名詞「情況」同理；
  「緊急情況、特殊情況」慣用，保留。）
- 心裡感到非常不勝榮幸 → 不勝榮幸。（不勝=非常，三重疊）

### B6. 動賓配搭不當

一個動詞管兩個賓語，只配得一個。

- 拉著小提琴和鋼琴。→ 拉奏小提琴，彈奏鋼琴。（演奏場景用具體演奏動詞；「拉著」只表示手部動作）
- 發揮了優良的成績。→ 取得了優良的成績。

### B7. 主謂/修飾語配搭不當

- 性格非常美麗 → 性格非常開朗
- 工作效率十分龐大 → 工作效率非常高
- 懷著一顆忐忑不安的心情 → 懷著忐忑不安的心
- 他性格隨便友善 → 他性格隨和友善
- 才能更充裕地完成家課 → 才有更充裕的時間完成家課

### B8. 語序不當

多層定語約按「領屬 → 指示 → 數量 → 動詞短語 → 形容詞 → 性質」。

- 一萬年前新出土的標本 → 新出土的一萬年前的標本
- 這首歌是今年這位歌手發表的作品。→ 這位歌手今年發表了這首歌。
- 這個農村糧食的生產，長期不能自給。→ 這個農村生產的糧食，長期不能自給。（定語掛錯中心語）

並列動作按客觀先後：「認真討論並表決通過」，唔係「表決通過並認真討論」。
關聯詞配對錯：「雖然今天天氣很好，而且我們去郊遊」→「因為今天天氣很好，所以我們去郊遊」。

### B9. 句式雜糅

兩種句式焊埋，拆返一種。

- 近視的主要原因是過度使用電子設備造成的。
  → 近視的主要原因是過度使用電子設備。（或：近視是由過度使用電子設備造成的。）
- 參賽者大多是以在校大學生為主。→ 參賽者大多是在校大學生。
- 成分是由純天然果汁配製而成。→ 成分是純天然果汁。

「主要目的，是為了……」拆一種：
「主要目的是提升服務質素」（保留程度義）或「旨在提升服務質素」（更正式）——
語氣唔同，按文類揀，冇唯一正解。

### B10. 一面對兩面

「能否/好壞/與否」兩面詞，對面都要兩面。

- 質量能否提高，是學校走向一流的關鍵保證。→ 兩邊同用「能否」，或兩邊都單向。

### B11. 多重否定翻車

防止、避免、切忌、為免本身含否定，後面勿再「不」。

- 為免公眾不再產生誤解。→ 為免公眾產生誤解。

### B12. 歧義

「三個學校的優秀教師」——校三所定師三人？
數量詞、修飾語位置、「下午一點半前去」類時間語有兩解 → 按實際重寫；
拿唔準：提問。

## 診斷目錄 C：官腔、套話與模糊標籤

### C1. 填充動詞

- 存在著許多困難 → 有許多困難
- 落實各項工作 → 執行工作（「落實法律規定」固定用法保留）
- 推進項目 → 開展項目
- 搭建平台 → 創造機會
- 打造品牌 → 創立品牌

極端副詞硬套：「嚴重同意、高度肯定、極度不滿」——程度詞同語義相撞，改實際配搭：一致贊成/深表關注/強烈不滿。
官腔「到位」配實體受詞（土地到位）生硬——按實際改：用地如期完成平整/資源如期交付。

### C2. 偽新詞

- 持份者（stakeholder 直譯，混淆責任）→ 按實際身分：學校師生、家長代表、業界同人
- 釋出善意 → 示好

「持份者」已係讀者熟悉通用詞可保留。

### C3. 物理術語濫用

- 語言高度濃縮 → 凝練
- 形勢出現變數 → 形勢有變

「寒蟬效應」「程序」（法規）固定概念保留。

### C4. 委婉語

- 優化人手 → 裁員
- 資源增值 → 加工作量

**注意**：公告可能刻意委婉，用戶要求直言或語境明確先揭穿；
勿擅改官方通告修辭成指控。

### C5. 口號直譯

- 向毒品說不 → 遠離毒品
- 我們準備好了 → 一切就緒

用戶刻意選用嘅標語照保留。

### C6. 模糊標籤與網絡語

情商低、內耗、拉胯、emo、破防——抽象標籤冇畫面。
改成可觀察行為與因果；概括用「不善於 X」好過「不太能 X」。

- 小明情商低，時常內耗，工作能力很拉胯。 → 小明不善於察覺他人感受，開會常打斷同事；遇到難題又反覆自我懷疑，
  遲遲難以決定，交付因而屢有延誤。

先理清實際行為、因果、影響再重寫；勿一組模糊詞換另一組模糊詞。
「不擅溝通、不善社交」仍係半抽象標籤——概括句可留一句，但要行為支撐：
講了什麼、做了什麼、別人如何反應。
「作出決定」屬 A1：「難以及時作出決定」→「難以及時決定」。
社交媒體語體且用戶刻意時保留。

## 修訂流程

1. 讀全文。
   標記：文類語域、受眾、引用/代碼/標語邊界、不可改內容（日期、數字、術語、承諾）。
2. 先修病句（目錄 B）：殘缺、配搭、雜糅、歧義、否定翻車。
3. 再掃歐化官腔（目錄 A、C）：只在遮蔽意思、拖節奏、生歧義時改。
4. 逐句回對原文：事實、數字、程度、語氣、術語無損；
   名詞化還原後動賓完整；補寫在原意內。
5. 按輸出契約交付。

## 交稿前檢查

- [ ] 原意、事實、數字、日期、承諾、術語、語氣無損。
- [ ] 每處修改都因清晰度或自然度，唔係因句式「像英文」；
      良性用法（正常被動、固定官式用語、技術術語、良性新詞）冇誤傷。
- [ ] 名詞化還原後，動詞自然帶上必要賓語，成分完整。
- [ ] 歧義已消；冇加原文冇嘅論點或事實。
- [ ] Markdown 結構一字不動：標題層級（#、##）、列表、表格、連結、程式碼、技術值；
      引文標語原文照錄。
- [ ] 香港慣用詞未換其他地域寫法；未被要求冇出現粵語口語。
- [ ] 未建立偏好且未禁止說明 → 文末有非阻塞提示；已要求只回傳修訂稿 → 冇加。
