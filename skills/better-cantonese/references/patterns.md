## 一 歐化句式（句法層）

中文靠動詞推進，英文靠名詞與虛詞搭建。
歐化非必錯：良幣（全球化、綠化——兩字講清複雜概念）對劣幣（進行、作出、情緒價值——累贅含糊）。
判準一條：意思不變、資訊清楚、讀者讀得順。以下逐型提醒檢查。

### 1.1 弱動詞+名詞化

| 病 | 修 |
| :--- | :--- |
| 委員會就經貿問題進行了緊急商討。 | 委員會緊急商討經貿問題。 |
| 院方已向病患家屬作出了正式的道歉。 | 院方已向病患家屬正式道歉。 |
| 警方昨天對涉案嫌疑人實施了逮捕。 | 警方昨天逮捕了涉案嫌疑人。 |
| 這部機器需要技術人員進行定期的維護。 | 這部機器需要技術人員定期維護。 |
| 探險隊準備對北極冰原從事一次艱苦的航行。 | 探險隊準備前往北極冰原艱苦航行。 |
| 他對她的告誡沒有作出任何理會。 | 他對她的告誡毫不理會。 |
| 我們正在進行彩排。 | 我們正在彩排。 |

**硬檢查**：刪弱動詞後，句子仍須像正常中文——動詞要自然帶上賓語。

- 他就全球化作匯報。→ 他就全球化議題匯報。/他以全球化為題作匯報。
- 同樣，「就此事作交代」應寫「交代事件經過」或「就此事作出交代」。

例外：「會議正在進行」「作出裁決」（公文體例）、「予以」有特定語氣時，可保留。

### 1.2 前飾過長（長定語前置）

英文關係子句直譯成前置定語，頭重腳輕。中文本行是後飾開放句——司馬遷示範：「籍長八尺餘，力能扛鼎，才氣過人」；主詞先行，一句一頓，越加越長也自然。

| 病 | 修 |
| :--- | :--- |
| 這是一座擁有超過五百年歷史同時完整保存了明清兩代建築風貌的古老宅院。 | 這座宅院歷史逾五百年，完整保存了明清兩代的建築風貌。 |
| 我想到了一條可以徹底解決目前財政赤字危機並安撫市場情緒的絕妙計策。 | 我想到了一條妙計，既可化解財政赤字，又能安撫市場情緒。 |
| 項籍是一個身高八尺，力能扛鼎，同時才氣過人的漢子。 | 籍長八尺餘，力能扛鼎，才氣過人。 |
| 這具小長毛象屍體是一萬年前新出土的天然標本。 | 這具小長毛象屍體新出土，是一萬年前的天然標本。 |

例外：法律、專利、產品規格依賴前置定語界定範圍時，保留固定結構。
政策公告的資格句、受惠句、數量句不屬此列——走定語謂語化拆句。

定語謂語化（名詞堆疊與資格條件類）——每層修飾自成分句，先條件、次資格、終後果：

- ❌ 就《行政長官2026年施政報告》當日或之後出生第二名或以後的子女，該名新生嬰兒的獎勵金將由2萬元提高至3萬元，為期三年。
  → ✅ 凡嬰兒在《行政長官2026年施政報告》發表當日或之後出生，排行第二或以後，獎勵金由2萬元增至3萬元，為期三年。
  （出生條件、排行資格、金額後果，各成分句；「就」框架刪。2026 施政報告句。）
- ❌ 增建三所資助獨立幼兒中心，預計於2030年年底前額外提供約1 800個零至三歲兒童日間照顧名額。
  → ✅ 增建三所資助獨立幼兒中心，2030年底前可多提供約1 800個名額，供零至三歲兒童日間照顧。
  （名詞堆疊「零至三歲兒童日間照顧名額」拆成動詞+目的句。2026 施政報告句。）

### 1.3 「的」字連環

| :--- | :--- |
| 參差的斑駁的黑影投在長長的寂靜的街道上。 | 參差而斑駁的黑影，落在寂靜的長街上。 |
| 彎彎的楊柳的稀疏的倩影倒映在湖面。 | 楊柳彎彎，將稀疏的倩影倒映在湖面。 |
| 灰暗的淒冷的天空迎來了夜色的來襲與風雨的將至。 | 灰暗而淒冷的天空下，夜色來襲，風雨將至。 |
| 那隻白色的鴨在有不潔的顏色的都市的河溝裡叫。 | 那隻白鴨在都市骯髒的河溝裡叫。 |
| 他拿出了一本封面泛黃的記載著家族歷史的珍貴的族譜。 | 他拿出一本珍貴的族譜，封面泛黃，載有家族歷史。 |

### 1.4 被動句濫用

中文的被動不只用「被」——替代字按事態語氣挑：
正面用「獲」「蒙」；中性用「給」「受」；負面用「遭」；
「當選/膺選/應邀」更自帶語態，連被動形都免。

| 病 | 修 |
| :--- | :--- |
| 曾蔭權先生如期被選為特首。 | 曾蔭權先生如期當選（膺選）特首。 |
| 香港常被稱為購物天堂。 | 香港素有「購物天堂」之美譽。 |
| 鋼琴家昨晚被邀請出席晚會。 | 鋼琴家昨晚獲邀出席晚會。 |
| 這部著作被廣大讀者熱烈歡迎。 | 這部著作深受讀者歡迎。 |
| 茶水已經被喝光了。 | 茶水已經喝光了。（無主被動） |
| 這項提議被董事會成員廣泛接受。 | 董事會成員普遍贊同這項提議。 |
| 未完成遷移的請求將被系統拒絕。 | 系統將拒絕未完成遷移的請求。（告示、系統通知的被字句即使事態負面也轉主動——告示要點是系統做什麼，主動更短、主體清楚） |

英文被動常為隱去施事而設；中文主動直陳即可：
'Firemen walk out from the building after the fire is put out.'
→ 「消防員撲滅火種後，離開大廈。」或「火撲滅後，消防員離開大廈。」

例外：被偷、被騙、被老闆辭退、太陽被烏雲遮住——不如意事態，正常中文，勿為避「被」而改。

### 1.5 量詞贅餘

- ❌ 家朗是一個小五學生。→ ✅ 家朗是小五學生。
- 數量可由上下文推斷：❌ 家朗去看一位醫生 → ✅ 家朗去看醫生（下文自然知道是哪一位）。

邊界例：「一位觀眾來信說……」——「觀眾」不便單稱，「之一」又累贅，由它去（余光中註）。

### 1.6 代詞與所有格堆砌

| 病 | 修 |
| :--- | :--- |
| 母親凝望著她的兒子，眼中流露出她的無盡關愛。 | 母親凝望著兒子，眼中流露出無盡關愛。 |
| 舅舅的雙手已經喪失了它們的一部份的靈活性。 | 舅舅的雙手已經有點不靈了。 |
| 一個軍人應該隨時為他的祖國獻出生命。 | 軍人當隨時為國家捐軀。 |
| 高達38%的受訪者說，他們晚上在街頭行走感到危險。 | ……說，晚上在街頭行走感到危險。（「他們」可省） |

例外：代詞與指涉對象相隔太遠時會誤讀（同段兩個「她」指不同人物）——重複名詞或補「自己」，以清楚為準。

### 1.7 介詞贅餘

| 病 | 修 |
| :--- | :--- |
| 關於他的申請，委員會今天進行了審查。 | 委員會今天審查了他的申請。 |
| 在這項新技術的研發上，我們耗費了三年時間。 | 研發這項新技術，我們耗費了三年時間。 |
| 歡迎王教授今天來到我們的中間。 | 歡迎王教授蒞臨。 |
| 由於他家境貧窮，使得他只好休學。 | 他家境貧窮，只好休學。 |
| 在環境保護的問題上，我們必須加強合作。 | 面對環境保護問題，我們必須加強合作。 |

告示致歉句：❌ 對於安排造成的不便，敬請體諒
→ ✅ 安排造成不便，敬請家長體諒。/不便之處，敬請家長體諒。

「就」較輕，「對於」較重；「透過/以」表真實手段關係且語域合適時可保留。

### 1.8 連詞贅餘

- ❌ 大會檢討了過去的工作，以及展望了未來，並通過了決議，與此同時頒發了獎項。
  → ✅ 大會檢討過去，展望未來，通過決議，頒發獎項。
- 開門七件事：柴米油鹽醬醋茶——不必「柴、米、油、鹽、醬、醋以及茶」。
- 「及」不能連動詞短語：❌ 專心上課及認真複習，是取得好成績的關鍵
  → ✅ 專心上課和認真複習……
- 「而」兼表轉折與更進一步：「慢而可靠」（slow but sure 不可作「慢及可靠」）；「學而時習之」的「而」有承接義。

例外：連詞承載真實邏輯關係（轉折、條件）時保留；兩個動作短語並列用「和」屬自然。

### 1.9 「當……的時候」

余光中譏為「當當之聲不絕於耳」。

- ❌ 當警報劃破寂靜夜空的時候，市民倉皇逃生。→ ✅ 警報驟響，市民倉皇逃生。
- ❌ 當我走到十字路口的時候，紅燈亮了。→ ✅ 我剛走到十字路口，紅燈正好亮起。
- ❌ 當問題被發現的時候，我們將會立即地進行處理。→ ✅ 發現問題後，我們會立即處理。

例外：需明確限定法律通知時點時，保留必要標記。

### 1.10 「們」字

- ❌ 聽眾們在聽完演講後，紛紛起立鼓掌。→ ✅ 聽眾聽完演講後……（集體名詞本身已表複數）
- ❌ 小鳥們在樹上唱歌。→ ✅ 群鳥在樹上唱歌。
- ❌ 人們常常在失去之後才懂得珍惜。→ ✅ 大家/世人往往失去後才懂得珍惜。
- ❌ 各位先生們、女士們 → ✅ 各位先生、女士

註：此病主要見於翻譯稿；香港本地原創文本少見。

### 1.12 機械「地」

| 病 | 修 |
| :--- | :--- |
| 她慢慢地走在林蔭小道上。 | 她徐徐漫步於林蔭小道上。 |
| 他冷漠地注視著匆忙地走過的行人。 | 他漠然注視著匆匆而過的行人。 |
| 遠處的晨霧靜靜地飄蕩在江面上。 | 遠處晨霧悠悠浮於江面。 |
| 國父孫中山先生成功地推翻了滿清。 | 國父孫中山先生推翻了滿清。（已推翻，何待「成功」） |
| 自動地發送通知。 | 自動發送通知。 |

長狀語「地」刪掉代以逗號，句法鬆筋：「他知其不可為而為之地還是去赴了約」→「他知其不可為而為之，還是去赴了約」。

註：此病主要見於翻譯稿；香港本地原創文本少見。

### 1.13 模糊程度詞

- ❌ 這項補貼政策在一定程度上緩解了貧困家庭的負擔。
  → ✅ 這項補貼政策略微（顯著）減輕了貧困家庭的負擔——按實際程度二擇一。
- ❌ 老張在本次科研攻關中，做出了有一定的貢獻。→ ✅ 老張在本次科研攻關中頗有貢獻。
- 真句（政府文本）：「政府會在相關情況下，以適當方式作出跟進。」——「適當方式」空泛程度語，實際處置隻字不提；按實際改，原文刻意含糊且屬正式表述時可保留。

### 1.14 時態硬譯

- ❌ 我們正在進行著討論，他已經是完成了工作。→ ✅ 我們正討論，他已完成工作。
- ❌ 他每天都做完了功課。→ ✅ 他每天都做功課。（習慣性動作與完成態衝突）
- ❌ 他曾經去過北京。→ ✅ 他曾去過北京。（「曾」「過」留一即可）

例外：「已、曾、正、將」表達的時間承諾必須保留——不可未來變現在、推測變確定。

### 1.15 長句無逗點

❌ 他甚至沒有因為這樁慘案而傷心得使他在法庭宣判那天無法維持一個專業律師應有的冷靜與為當事人爭取權益的決心。
✅ 遭逢這樁慘案，他固然傷痛，但在法庭宣判當天，仍維持了律師應有的冷靜，決心為當事人爭取權益。

### 1.16 框架句（重心後置）

存在句虛主詞+目的框架同屬此病：先繞一個空框架，才說實義。

- ❌ 這裏一定有她缺席的原因。→ ✅ 她缺席一定有原因。
- ❌ 這個方案有值得商榷的地方。→ ✅ 這個方案值得商榷。
- ❌ 本次版本更新旨在改善使用者在登入流程中遇到的問題，並加入了新的驗證方式。
  → ✅ 本次版本更新了新的登入驗證方式，旨在改善使用者在登入流程中遇到的問題。
  （實義動作/新聞先行，目的框架收尾；「旨在改善」開頭把真正的更新埋進目的從句。）

例外：「有」表真實存在（「桌上有一本書」）不屬此類；
邊界例（保留）：「目前已經有超過100間科技企業及機構簽約進駐」——「有」帶可數名單，真實存在，合法。（真實公報句）

### 1.17 名詞化主語/受詞

| 病 | 修 |
| :--- | :--- |
| 他的收入的減少改變了他的生活方式。 | 他因為收入減少而改變生活方式。 |
| 橫貫公路的再度坍方，是今日的頭條新聞。 | 橫貫公路再度坍方，是今日的頭條新聞。 |
| 他們杯葛這種風俗的繼續。 | 他們反對保存這種風俗。 |
| 書籍的選購，只好委託你了。 | 選購書籍，只好委託你了。 |

要害：中文以具體名詞、尤其人做主語；「……的+雙音節動詞」做主語受詞是英文語法流露。

### 1.18 「……之一」

- ❌ 紅樓夢是中國文學的名著之一。→ ✅ 紅樓夢是中國古典文學的巔峰之作。（「之一」蛇足——沒有人會誤會你孤陋寡聞）
- ❌ 李廣乃漢朝名將之一。→ ✅ 李廣乃漢朝一代名將。
- ❌ 作為竹林七賢之一的劉伶以嗜酒聞名。→ ✅ 劉伶是竹林七賢之一，以嗜酒聞名。
  （「作為」純然多餘；也可「劉伶列於竹林七賢」「劉伶躋身竹林七賢」）
- ❌ 這是當前治理面臨的最棘手的難題之一。→ ✅ 這是當前治理極為棘手的難題。（「最」抬到至高，「之一」又稍加低抑，兜一圈等於沒說）

邊界例（保留）：「香港是全球三大藝術品交易中心之一」——「三大」名單可考，屬合法「之一」。（真實公報句）

## 二 病句（語法層）

### 2.1 主語殘缺

| 病 | 修 |
| :--- | :--- |
| 通過這次嚴格的專業技術培訓，使他的業務水準大幅提高。 | 這次嚴格的專業技術培訓，使他的業務水準大幅提高。（或：通過這次培訓，他的業務水準……） |
| 在老師的悉心教導下，讓我明白了閱讀的真正樂趣。 | 老師的悉心教導，讓我明白了閱讀的真正樂趣。 |
| 從大量的考古實物觀測中，證實了這段歷史的真實性。 | 大量的考古實物，證實了這段歷史的真實性。 |
| 在他的座位上放了旅行的照片。 | 他在座位上放了旅行的照片。（刪句首「在」，主語現身；「他座位上放了照片」則陳述事實，重點不同） |
| 對這班同學來說，關係很親密。 | 這班同學關係很親密。（刪「對……來說」） |
| 由於她的努力，最後贏了比賽。 | 她很努力，最後贏了比賽。 |

無主句提醒：同段主語一致時，承前省略是中文常態，不必逐句補主語
（龍應台示範：「那麼認真地看，專注而嚴肅，而且看了起碼半個小時……」）。

### 2.5 同義重複

- ❌ 我會拒絕一切任何誘惑。→ ✅ 拒絕任何誘惑（強調決心可加狀語：絕對會拒絕）。
- ❌ 預先安排、徹底根治、親自示範、虛假失實、重複再做。→ ✅ 安排、根治、示範、失實、再做。
- ❌ 經濟損失高達上千萬元之巨。→ ✅ 經濟損失高達上千萬元。
- ❌ 這座古城在海內外聞名遐邇。→ ✅ 這座古城聞名遐邇。
- ❌ 他在會上提出了許多具有真知灼見的意見。→ ✅ 提出了許多真知灼見。
- ❌ 他在心裡由衷地感謝老師。→ ✅ 他由衷地感謝老師。
- ❌ 往事歷歷在目地出現在眼前。→ ✅ 往事歷歷在目。
- ❌ 這是各級部門責無旁貸的責任。→ ✅ 這是各級部門責無旁貸的義務。（或：各級部門責無旁貸）
- ❌ 心裡感到非常不勝榮幸。→ ✅ 不勝榮幸。（「不勝」即「非常」，三重疊）

保留例：❌ 去年夏季，安徽省和江蘇省兩省大部分地區遭受嚴重洪澇災害——「兩省」貌似多餘，刪了即生歧義（哪省的大部分？）。範圍詞有辨義功能時保留。（NoteSity 實戰題）

### 2.6 成分多餘細分

- 主語多餘：❌ 我們考試前努力溫習，我們亦虛心求問。→ ✅ 刪第二個「我們」。
- 賓語多餘：❌ 兩地通航飛機後，貿易往來愈趨頻繁。→ ✅ 兩地飛機通航後……（「通航」不及物）
- 隱含態誤加：❌ 被應邀出席、被當選為理事、實屬是違法行為 → ✅ 應邀、當選、實屬。
- 謙辭誤加：❌ 歡迎各位蒞臨我的寒舍。→ ✅ 歡迎各位蒞臨寒舍。（謙辭自帶屬格）
- 空洞分句：❌ 從食物鏈角度來看，可以清楚知道，植物吸收陽光……→ ✅ 刪「可以清楚知道」——不裝載新資訊的分句。
- 填充名詞：「緊急情況」「特殊情況」慣用，保留；湊數的「情況/地方/方面」能刪則刪。

### 2.9 語序不當

- 多層定語（領屬→指示→數量→動詞短語→形容詞→性質）：
  ❌ 這首歌是今年這位歌手發表的作品。→ ✅ 這位歌手今年發表了這首歌。（重點是「誰做了什麼」）
  ❌ 這是一件羊皮新買的哥哥的貴重大衣。→ ✅ 這是哥哥新買的一件貴重的羊皮大衣。
- 多層狀語（目的→時間→處所→範圍→情態→對象）：
  ❌ 我在學校昨天看見了老師。→ ✅ 我昨天在學校看見了老師。
  ❌ 我們把這件事不告訴他。→ ✅ 我們不把這件事告訴他。
- 並列動作按客觀先後：❌ 表決通過並認真討論了這項規劃 → ✅ 認真討論並表決通過了這項規劃。
- 範圍遞進按實際：❌ 這種藥不僅能徹底治癒晚期病患，而且能有效緩解早期症狀。→ ✅ 不僅能有效緩解早期症狀，而且能徹底治癒晚期病患。
- 關聯詞配對錯：❌ 雖然今天天氣很好，而且我們去郊遊。→ ✅ 因為今天天氣很好，所以我們去郊遊。（邏輯是因果，不是轉折）
- 前半關聯詞脫落：❌ 他平時成績並不突出，但是在這次大賽中一舉奪魁。→ ✅ 雖然他平時成績並不突出，但是……。

### 2.10 句式雜糅

| 雜糅 | 拆法 |
| :--- | :--- |
| 主要原因是……造成的 | 主要原因是……/是由……造成的 |
| 原因是因為…… | 原因是……/是因為…… |
| 是由於努力的結果 | 是由於努力/是努力的結果 |
| 大多是以……為主 | 大多是……/以……為主 |
| 旨在以……為目的 | 旨在……/以……為目的 |
| 是為了……的目的 | 是為了……/目的是…… |
| 成分是由……配製而成 | 成分是……/由……配製而成 |
| 有……等七個大項組成 | 包括……等七個大項/由……組成 |
| 需要非……不可 | 需要……/非……不可 |

例：❌ 青少年近視的主要原因是過度使用電子設備造成的。
→ ✅ 青少年近視的主要原因是過度使用電子設備。（或：近視是由過度使用電子設備造成的。）

「主要目的，是為了……」拆一種：「主要目的是提升服務質素」（保留程度義）或「旨在提升服務質素」（更正式）——語氣不同，按文類選擇，沒有唯一正解。

## 三 詞彙層：官腔、套話與標籤

### 3.1 官腔填充動詞與搭配

| 病 | 修 |
| :--- | :--- |
| 存在著許多困難。 | 有許多困難。 |
| 推進項目發展。 | 開展項目。 |
| 搭建交流平台。 | 創造交流機會。 |
| 打造新品牌。 | 創立新品牌。 |
| 本會致力於服務增值與程序優化。 | 本會致力提升服務質素與簡化步驟。 |

（註：「落實X→執行X」不收入此表——那是同義換字，不是修復；見下方實義動作規則。）

- 程度詞與語義相撞：❌ 高度肯定、極度不滿 → ✅ 深表關注、強烈不滿（按實際配搭）。
  ❌ 委員會對方案嚴重同意 → ✅ 委員會對方案完全同意。
  **範圍警告**：程度詞替換不可引入範圍/共識語義——「一致贊成」把「同意」變成「全體同意」，是添加原文沒有的事實。
  語理拿不準（誰對誰、範圍多大）→ 保守中性詞+一句非阻塞確認（見 SKILL.md〈語理優先〉）。
- 官腔動詞須改成**實義動作**，同義換字不算修復：
  ❌ 全力推進新田科技城 → ❌ 全力推展新田科技城（只是換字，官腔未除）
  → ✅ 全力推動新田科技城首階段興建/加快發展新田科技城（按實際工程內容講動作）。（真實公報句演變）
- 官腔「到位」配實體受詞生硬：❌ 創科土地陸續如期到位 → ✅ 創科用地如期完成平整。（真實公報句；官腔「到位」取代了具體動作，按實際還原）
- 官腔動詞須換成實義動作：「推進→推展」類同義換字不算修復——
  按語境改「推動興建」「發展」「興建」類實義表達。
- 「優化」有明確技術定義（算法優化、流程優化有具體對象）時保留。

### 3.2 委婉語

- 待業/下崗→失業；優化人手/縮減規模→裁員；資源增值→減薪或加工作量；富餘人員→過剩人力。
- 邊界（保留或按語境）：公告刻意委婉屬官方修辭，勿擅改官方通告成指控；
  「適當跟進」（真實公文通用委婉語）、「不良營商手法」（執法術語）按語境保留或具體化。

### 3.3 偽新詞與支語

- ❌ 教育界持份者（stakeholder 直譯，混淆責任）→ ✅ 教育界同人/學校師生/家長代表——按實際身分還原。
  邊界：「持份者」已是讀者熟悉的通用詞，可保留。
- ❌ 政府釋出善意（release goodwill 直譯）→ ✅ 政府示好/表示友好。
- 支語還原示範（香港語文研習平台例——還原成香港讀者本來會講的說法）：
  情緒價值→哄你開心、安慰、鼓勵、體貼；
  鬆弛感→從容、自在、處之泰然；
  高情商→圓滑、世故、察言觀色；
  內耗→憂慮、胡思亂想、患得患失。
  詞彙替代是治標；語理不通時先梳理邏輯（見 SKILL.md〈提問時機〉）。

### 3.4 術語域滑用

- ❌ 本書語言高度濃縮。→ ✅ 本書語言凝練。
- ❌ 形勢出現變數。→ ✅ 形勢有變。
- ❌ 部署航班安排。→ ✅ 編排航班。（「部署」由軍事語域濫入行政）
- ❌ 「全面準備，廣泛和深化部署，把破壞降低。」→ ✅ 充分準備、適時調整，減低破壞。（工程/軍事語域滑入民生；真實官員原句）
- 保留：寒蟬效應、法律「程序」（法規語域固定概念）。

### 3.5 口號直譯與告示對象錯亂

| 病 | 修 |
| :--- | :--- |
| 向毒品說不！ | 遠離毒品！ |
| 為夢想創造可能。 | 助你實現夢想。 |
| 生命有 Take 2。 | 人無再少。 |
| 狗隻不准進入。 | 請勿攜犬入內。（命令面向人，不面向狗） |
| 牽引你的大型狗隻。 | 大犬須用牽帶。 |

邊界：「Q版公仔」「M形底座」在設計、科技語域通行，屬約定俗成，慎改；
用戶刻意選用的標語照保留。

真實告示語料（語域參考，非病句）：
「受檢人士如有病徵，應立即求醫，按照醫護人員的指示接受檢測，不應前往流動採樣站及社區檢測中心。」（指令堆疊長句）
「家長無須回覆中學是否接受有關自行分配學位。」（標準「無須……是否」結構）

### 3.6 籠統濫情詞

- ❌ 飲食文化、茶文化、酒文化。→ ✅ 飲食風俗、茶道/茶藝。（回歸實指）
- ❌ 熱烈慶祝、偉大成就。→ ✅ 慶祝；成就按實際程度講（何謂偉大，拿出標準或刪）。

### 3.7 模糊標籤（改寫手法示範）

❌ 小明情商低，時常內耗，工作能力很拉胯。

先看語理：即使把「支語」全換成香港用語——「小明不擅溝通，時常憂慮，工作能力很差」——依然不通：三件事堆在一起，因果沒有交代。

✅（假設線索：會上常打斷同事；遇難題反覆自我懷疑致交付延誤）
他不善於察覺他人感受，開會常打斷同事；遇到難題又反覆自我懷疑，遲遲難以決定，交付因而屢有延誤。

規則：
- 例句細節必須來自原文或用戶線索，示範非模板——原文有線索→按線索具體化。
- 純標籤沒有任何事實→不作故事（虛構「開會打斷同事」寫成確定事實=臆測），
  照交保守版本+問實情（見 SKILL.md〈提問時機〉）。
- 「不擅溝通、不善社交」仍是半抽象標籤——概括句可留一句，但要行為支撐。
- 社交媒體語體且用戶刻意時保留。

## 四 AI 腔與數位退化

### 4.1 「不是 A 而是 B」模板

- ❌ 不是生動活潑的東西，而是死硬的東西。→ ✅ 東西死硬，不夠生動活潑。
- 判準：真對比（「不是他不想去，而是去不了」）保留；
  先立稻草人再反駁的修辭性假對比拆掉，改直接陳述。

### 4.2 雙重連接

- ❌ 由於天氣惡劣，因此活動取消。→ ✅ 天氣惡劣，活動取消。
- 例外：條款、法律文本需明示因果鏈時，留一個連詞。

### 4.3 AI 黑名單詞彙

| AI 歐化詞 | 實義替代 |
| :--- | :--- |
| 深入探討 | 探討/細論 |
| 至關重要 | 極重要/關鍵 |
| 值得注意的是 | 留意/須知 |
| 顯而易見 | 明顯 |
| 我們認為 | 按實際主體（輿論/研究團隊/筆者） |
| 關鍵在於 | 在於/要點是 |
| 黃金合作方案 | 合作方案（「黃金」是模板贅詞） |
| 進行中 | 正在進行 |
| 積極影響 | 好影響/助益 |
| 負面影響 | 壞影響/害處 |
| 令人興奮 | 振奮 |
| 充滿挑戰 | 艱難/挑戰大 |
| 賦能 | 按實際動作（支援、提升、協助） |
| 抓手 | 按實際手段（工具、切入點） |

判準不是禁詞表：語域需要（學術摘要的「值得注意的是」）可保留；
高頻套路堆疊先清。AI 偵測信號：這些詞與「不是A而是B」「由於…因此」同現時，幾可斷定是生成文本。

### 4.5 emoji 代文

## 五 語篇層：話語修辭

啟用條件重申：只在用戶要求「改得客觀/中立/去宣傳腔」時動這層；
純潤稿不改論證立場；引述、翻譯、政治評論分析——原文立場係分析對象時一字不動。

1. **事實與看法混淆**：❌ 我國體制具有無可比擬的優越性，形勢一片大好。
   → ✅ 數據顯示居民收入有所增長，社會保障體系正逐步完善。（可檢驗的內容）
2. **道德標籤定性**：❌ 一小撮別有用心之徒公然發表妄言。
   → ✅ 部分評論員對該政策提出不同意見。（中性描述+具體行為）
3. **虛擬集體代理人**：❌ 廣大群眾一致堅決擁護這項收費政策。
   → ✅ 多數受訪民眾對此表示理解。（須有真實依據；無依據→保守表述或質疑出處）
4. **非黑即白**：❌ 如果不堅持這條道路，國家必然四分五裂、萬劫不復。
   → ✅ 堅持現行道路有助維持政局穩定與經濟平穩。（改可檢驗命題，去恫嚇）
5. **比爛（whataboutism）**：❌ 你們自己人權記錄劣跡斑斑，有何資格指手畫腳？
   → ✅ 就報告提出的具體案件程序問題，主管部門將依法核查答覆。
6. **動機論**：❌ 其背後必定受境外敵對勢力資助。
   → ✅ 就研究引用的數據來源與結論本身辯析。
7. **循環論證**：❌ 我們必須擁護這項制度，因為它代表最先進方向，所以是唯一正確的制度。
   → ✅ 支持該制度的理據，在於其歷年促進社會穩定與經濟增長的可量化成效。
8. **絕對化**：❌ 穩定是壓倒一切的重中之重，必須全面、徹底、百分之百落實。
   → ✅ 維持穩定是發展前提，各部門應結合實況，嚴謹履行職責。
9. **數字口訣密碼**：❌ 牢記「四個全面」、「六個突出」，做到融會貫通。
   → ✅ 展開為實義內容：法治、廉政、經濟發展等重點領域的要求。
10. **半真話**：❌ 憲法白紙黑字保障公民自由，足見人權已達歷史最高水平。
    → ✅ 憲法載明保障公民權利；執行層面的保障仍需完善。（補全語境）
11. **公文體統崩壞**：❌ 請你務必撥冗出席，給香港市民一個面子。
    → ✅ 敬祈閣下撥冗蒞臨主持，以慰全港市民之盼。（敬語謙辭按場合恢復；謙辭勿加物主——見 2.6）

## 搭配自測（理據）

背景：LLM 訓練資料被官腔公文污染（土地到位、全力推進、抓好落實、打造XX）。

- 「讀得順」的直覺本身可能已中毒——高頻錯搭配正是生成時機率最高的下一個詞。
- 所以搭配對錯不靠直覺，靠可執行的測試。對替換詞、原文疑點搭配都做：
  1. 定義測試：一句說出動詞定義，受詞符合條件嗎？
     「落成」=建築物完工；土地不是建築物，廢。
  2. Pivot 測試：改直白中文或英文說一次——講不順，廢。
  3. 畫面測試：想像不到動作實際發生，疑，回查。
  三測有廢：換搭配或重組。
- 語言學基礎是 selectional preferences（動詞對論元的語義類型限制）：
  不必列搭配表，測類型兼容。語料庫研究（Chinese Word Usage Errors、OCCA 搭配資源）同樣以「搭配錯配=語義不合」為判準。

兩類錯誤要分開：

- **類型錯誤**（土地落成、拉著鋼琴）——搭配自測可通用偵測，不必詞典。
- **語體錯誤**（打造、推進、到位、賦能）——搭配本身「通」，只是官腔；靠詞彙層目錄逐個養，發現一個入一個。

## 修訂手法例（文白相濟）

告示體——實事先行，目的從屬：

- ❌ 本次版本更新旨在改善使用者在登入流程中遇到的問題。
  → ✅ 本次版本更新了新的登入驗證方式，旨在改善使用者在登入流程中遇到的問題。
  （開場自我描述是空轉；讀者要先知道「做了什麼」。）

凝縮對偶——官方自鑄語還原為四字收束：

- ❌ 由「投訴後治理」變為「未投訴已治理」的主動防禦模式。
  → ✅ 投訴未至，問題先治。
  （自鑄語非引語，保護的是資訊與責任，不是措辭；
   對偶收句用於公文、公報語域；散文敘事勿強行對偶。）

## 提問時機

原則：臆測=作故事。證據夠直接改；不夠就問——
但照交最合理修訂（語理優先），不拿問題擋交付。

為何問：抽象標籤與官腔詞取代了具體觀察——
寫的人自己往往沒想清楚發生過什麼。
詞彙替代治標；查明實情，改寫才有畫面。你改不出，好多時因為文本無講。

| 訊號 | 例 | 行動 |
| :--- | :--- | :--- |
| 純標籤沒有事實 | 小明情商低，時常內耗 | 保守版本（事實留白）+問實情 |
| 歧義兩解拿不準 | 三個學校的優秀教師 | 照交一解+問邊個啱 |
| 語理罅隙 | 因果斷纜、關係沒有交代 | 照交+講出理解請確認 |
| 立場/施受關係拿不準 | 「對反對意見則極度不滿」（誰對誰？） | 保守改寫+標明理解請確認 |
| 原意拿不準 | 數字、承諾、立場不清 | 保留原樣+問 |

問法：一至兩句、非阻塞、具體——要行為/事例/影響，不是「請提供更多資料」。
用戶要求只回傳修訂稿：省略問句，自選最合理讀法。

## 地域與語體資料

- 香港慣用詞（正確用語，勿「修正」）：屋苑、升降機、查詢、登記、質素、樓宇、巴士、的士、方便（形容詞用法）。
- 北方口語入通用書面語時改書面語：「咋辦」→如何處理、「腦袋瓜子」→頭腦靈敏、「啥」→什麼、「搞快點」→抓緊時間。
- 「裡/裏」：香港書面語兩者皆見，跟隨原文或全文一致性，不強行統一。
- 品牌、產品名、技術縮寫：保留大小寫。
- 日期、數字、貨幣、單位：依原格式，只在全文不一致或誤讀時統一。
- 法律、醫療、政策術語與條文語體：跟官方或原文既有寫法。
