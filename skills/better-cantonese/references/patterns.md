## A 歐化句式（翻譯腔）

中文靠動詞推進，英文靠名詞與虛詞搭建。歐化中文不是一律要除：余光中認為善用歐化可使中文活潑；「全球化」「綠化」等詞無地道替代，屬有益歐化。要除的是「生澀的翻譯腔」——遮蔽動作、拖慢節奏、堆砌虛詞。

### A1 弱動詞+名詞化（義肢動詞）

「進行/作出/予以/加以/實施/展開」+雙音節動詞，把及物動詞降格為抽象名詞。中文的力氣在動詞，這類結構把引擎拆走，句子失去動感。

| 病 | 修 |
| :--- | :--- |
| 委員會就經貿問題進行了緊急商討。 | 委員會緊急商討經貿問題。 |
| 院方已向病患家屬作出了正式的道歉。 | 院方已向病患家屬正式道歉。 |
| 警方對嫌疑人實施了逮捕。 | 警方逮捕了嫌疑人。 |
| 這部機器需要技術人員進行定期的維護。 | 這部機器需要技術人員定期維護。 |
| 他對告誡沒有作出任何理會。 | 他對告誡毫不理會。 |
| 因應道路將會進行改善工程。 | 因應道路改善工程。（「改善工程」本身是名詞，勿再掛「進行」） |

例外：「會議正在進行」「作出裁決」（公文體例）、「予以」有特定語氣時，可保留。還原名詞化後必須回看動賓：具體動詞能否自然帶上原賓語？「對全球化進行匯報」→「匯報全球化議題」/「以全球化為題作匯報」，不是刪字了事。

### A2 「的」字連環

英文關係子句直譯成前置定語，「的」字成災。

| 病 | 修 |
| :--- | :--- |
| 那隻白色的鴨在有不潔的顏色的都市的河溝裡叫。 | 那隻白鴨在都市骯髒的河溝裡叫。 |
| 這是一個很難被大眾所理解的非常複雜的社會現象。 | 這個社會現象極其複雜，大眾殊難理解。 |
| 他拿出了一本封面泛黃的記載著家族歷史的珍貴的族譜。 | 他拿出一本珍貴的族譜，封面泛黃，載有家族歷史。 |

### A3 大帽子句（長定語前置）

修飾子句整捆塞入名詞之前，頭重腳輕。先給主幹，再後置補充。

| 病 | 修 |
| :--- | :--- |
| 我見到一個長得像你兄弟說話也有點像他的陌生男人。 | 我見到一個陌生男人，長得像你兄弟，說話也有點像他。 |
| 這是一座擁有超過五百年歷史同時完整保存了明清兩代建築風貌的古老宅院。 | 這座宅院歷史逾五百年，完整保存了明清兩代的建築風貌。 |
| 我想到了一條可以徹底解決目前財政赤字危機並安撫市場情緒的絕妙計策。 | 我想到了一條妙計，既可化解財政赤字，又能安撫市場情緒。 |
| 這個涉及開支約10億的建議可讓70萬人受惠。 | 這個建議涉及開支約10億，可讓70萬人受惠。 |

例外：法律、專利、產品規格依賴前置定語界定範圍時，保留固定結構。

### A4 濫用「被」

中文「被」傳統多含不如意、受損。中性或正面事態改主動、「獲/受/當選/應邀」，或無主句。

| 病 | 修 |
| :--- | :--- |
| 曾先生如期被選為特首。 | 曾先生如期當選特首。 |
| 鋼琴家昨晚被邀請出席晚會。 | 鋼琴家昨晚獲邀出席晚會。 |
| 茶水已經被喝光了。 | 茶水已經喝光了。 |
| 這項提議被董事會廣泛接受。 | 董事會普遍贊同這項提議。 |
| 這部著作被廣大讀者熱烈歡迎。 | 這部著作深受讀者歡迎。 |
| 相關請求將會被系統拒絕。 | 系統將拒絕相關請求。（告示要點是系統做什麼；主動更短。轉主動時可順手把「相關/有關」泛稱還原為具體所指，原意內含時：系統將拒絕舊版請求。） |

保留：「被老闆辭退」「太陽被烏雲遮住」「被多次修改的條款」——不如意、自然現象或焦點在承受者時，「被」是正常中文。「獲」本身已含承受義，「被人們廣泛接受」的「被人們」是贅餘。

### A5 濫用「一個」

英文冠詞直譯。「家朗是一個小五學生」→「家朗是小五學生」。「這是一個很難理解的問題」→「這個問題很難理解」。真要計數時才用。

### A6 萬能連詞

and 見句必插，破壞中文並列節奏。

| 病 | 修 |
| :--- | :--- |
| 柴、米、油、鹽、醬、醋以及茶。 | 柴米油鹽醬醋茶。 |
| 一年有春、夏、秋和冬四季。 | 一年有春夏秋冬四季。 |
| 大會檢討了過去的工作，以及展望了未來，並通過了決議。 | 大會檢討過去，展望未來，通過決議。 |

例外：「及/和/以及」連接兩個動作短語（「專心上課和認真複習」）時常屬自然；連詞承載真實邏輯關係（轉折、條件）時保留。

### A7 代詞與所有格堆砌

中文承前省略是常態；英文的 his/it/they 照抄則生澀。

| 病 | 修 |
| :--- | :--- |
| 一個軍人應該隨時為他的祖國獻出生命。 | 軍人當隨時為國家捐軀。 |
| 母親看著她的兒子，眼中充滿了她的關愛。 | 母親凝望著兒子，眼中滿溢關愛。 |
| 當張先生見到他的朋友時，他對他說…… | 張先生見到朋友，說…… |

指涉可能混淆時（「他告訴小明，他明天會提交報告」）補回「自己」或名詞，以清楚為準。

### A8 「……之一」

one of the... 直譯，削弱判斷句態。

| 病 | 修 |
| :--- | :--- |
| 《紅樓夢》是中國文學史上的名著之一。 | 《紅樓夢》是中國古典文學的巔峰之作。 |
| 這是當前治理面臨的最棘手的難題之一。 | 這是當前治理極為棘手的難題。 |

真要表達「多個成員中的一個」且名單可考時，保留。

### A9 介詞外框

關於、對於、在……上/方面、作為、透過……來……

| 病 | 修 |
| :--- | :--- |
| 關於他的申請，委員會今天進行了審查。 | 委員會今天審查了他的申請。 |
| 在環境保護的問題上，我們必須加強合作。 | 面對環境保護問題，我們必須加強合作。 |
| 歡迎李教授今天來到我們的中間。 | 歡迎李教授今天蒞臨。 |
| 透過進行系統升級來改善登入體驗。 | 透過系統升級改善登入體驗。 |
| 對於這些不禮貌的行為，我不能不質疑。 | 這些不禮貌的行為，我不能不質疑。（話題可作賓語直陳時刪框；「就」較輕，「對於」較重） |
| 對於安排造成的不便，敬請體諒。 | 安排造成不便，敬請家長體諒。（或：不便之處，敬請家長體諒。） |
| 由於他家境貧窮，他只好休學。 | 他家境貧窮，只好休學。（因果關係清楚時，「由於/因為」可整個省去，中文靠語序表邏輯） |

「透過/以」表達真實手段關係且語域合適時可保留，不必為避詞而改。

### A10 「當……的時候」

余光中：「當當之聲不絕於耳」。時間關係清楚時刪。

| 病 | 修 |
| :--- | :--- |
| 當警報劃破寂靜夜空的時候，市民倉皇逃生。 | 警報驟響，市民倉皇逃生。 |
| 當我走到十字路口的時候，紅燈亮了。 | 我剛走到十字路口，紅燈正好亮起。 |
| 當問題被發現的時候，我們將會立即地進行處理。 | 發現問題後，我們會立即處理。 |

需要明確限定時間界線或法律通知時點時，保留必要標記。

### A11 「們」字成災

「聽眾們、運動員們、先生們女士們、桌子們」一律刪「們」；集體名詞（聽眾、觀眾、群眾）本身已表複數；「人們」→「大家/世人」；「小鳥們」→「群鳥」。

### A12 抽象名詞後綴

-ability/-ness/-ization 直譯。

| 病 | 修 |
| :--- | :--- |
| 這部小說的可讀性非常高。 | 這部小說引人入勝。 |
| 他的言論帶有強烈的侮辱性。 | 他的話極其無禮。 |
| 他在學生中具有極高的知名度。 | 他在學生中聲名遠播。 |
| 體操動作的難度非常大。 | 體操動作極難。 |

技術術語（硬度、黏度、濃度、效率）與固定概念（寒蟬效應）保留。

### A13 機械「地」

-ly 直譯。中文有疊字、擬聲、文言副詞。

| 病 | 修 |
| :--- | :--- |
| 她慢慢地走在林蔭小道上。 | 她徐徐漫步於林蔭小道上。 |
| 他冷漠地注視著匆忙地走過的行人。 | 他漠然注視著匆匆而過的行人。 |
| 自動地發送通知。 | 自動發送通知。 |

「持續地密切關注」→「密切留意」類的疊加尤須清理。

### A14 模糊程度詞

「在一定程度上」「做出了一定的貢獻」「某程度上」——逃避判斷的修辭盾牌。按實際改：略微、顯著、頗有、大致。原文刻意含糊且屬正式表述時可保留。

### A15 時態硬譯

「正在進行著討論」→「正在討論」；「已經是完成了」→「已完成」；「他曾經去過」視語境可留「曾/過」之一。「他每天都做完了功課」→「他每天都做功課」——習慣性動作與完成態衝突。**時間與承諾不可刪失**：「將於下週發布」的「將」、「已於昨日完成」的「已」，刪了就是把未來變現在。

### A16 長句無逗點

中文靠逗號呼吸。超長句先找主謂賓，按邏輯斷句：

❌ 他甚至沒有因為這樁慘案而傷心得使他在法庭宣判那天無法維持一個專業律師應有的冷靜與為當事人爭取權益的決心。
✅ 遭逢這樁慘案，他固然傷痛，但在法庭宣判當天，仍維持了律師應有的冷靜，決心為當事人爭取權益。

### A17 存在句虛主詞

there be 句式直譯：「有……的原因/情況/可能」托住空洞尾詞，重心被拖到句尾。把重心移前，讓真主語當家。

| 病 | 修 |
| :--- | :--- |
| 這裏一定有她缺席的原因。 | 她缺席一定有原因。 |

「有」表真實存在（「桌上有一本書」）不屬此類。

## B 病句

### B1 主語殘缺（介詞吞主語）

| 病 | 修 |
| :--- | :--- |
| 通過這次培訓，使他的水準大幅提高。 | 這次培訓使他的水準大幅提高。（或：通過培訓，他的水準大幅提高。） |
| 在老師的悉心教導下，讓我明白了樂趣。 | 老師的悉心教導，讓我明白了樂趣。 |
| 從大量的考古實物觀測中，證實了歷史的真實性。 | 大量的考古實物，證實了歷史的真實性。 |
| 在他的座位上放了旅行的照片。 | 他在座位上放了旅行的照片。 |

### B2 暗中換主語

| 病 | 修 |
| :--- | :--- |
| 小張表現突出，安排他任副主任。 | 小張表現突出，上級安排他任副主任。（或：……因而獲委任為副主任。） |
| 這名小選手一舉奪金，受到了組委會的通報嘉獎。 | 這名小選手一舉奪金，組委會對其予以通報嘉獎。（或：……並獲組委會通報嘉獎。） |

### B3 謂語殘缺

| 病 | 修 |
| :--- | :--- |
| 我不能不疑問。 | 我不能不質疑。 |
| 這種高粱不僅畝產量極高，而且比進口高粱更強的抗旱能力。 | ……而且比進口高粱具有更強的抗旱能力。 |
| 全體員工積極為公司的未來發展。 | 全體員工積極為公司的未來發展而奮鬥。 |

### B4 賓語殘缺

| 病 | 修 |
| :--- | :--- |
| 老師若能設身處地，便能明白學生。 | ……便能明白學生的難處/體諒學生。 |
| 這部劇成功塑造了幾位熱血抗日青年的故事。 | 這部劇成功塑造了幾位熱血抗日的青年形象。 |

補寫須是原意內含，不可添新事實。

### B5 同義重複

成功當選、一切任何、大約……左右、高達……之巨、目前的當務之急、聞名遐邇的海內外、真知灼見的意見、由衷地在心裡感謝、歷歷在目地出現在眼前、責無旁貸的責任、預先安排、重複再做、虛假失實、親自示範、徹底根治。各刪冗餘一半。「心裡感到非常不勝榮幸」→「不勝榮幸」——「不勝」本身即「非常」，三重疊。

「感到/覺得」配本身已自足的情感詞亦冗餘：聽到琴聲，感到十分感動→十分感動；聽到消息，感到十分欣慰→十分欣慰。但「感到失望、感到自豪、感到意外」屬自然用法——「感到」不是禁詞，只在語義重疊時刪。

填充名詞「情況」同理：系統偵測到異常情況時→偵測到異常時；「在……的情況之下」常可整個刪減。但「緊急情況、特殊情況」屬慣用搭配，保留。

### B6 動賓配搭不當

| 病 | 修 |
| :--- | :--- |
| 樂手盡情拉著小提琴和鋼琴。 | 樂手盡情拉奏小提琴，彈奏鋼琴。（演奏場景用具體演奏動詞；「拉著」只表示手部動作） |
| 運動員發揮了優良的成績。 | 運動員取得了優良的成績。 |
| 好朋友應互相分擔快樂和憂愁。 | 好朋友應互相分享快樂，分擔憂愁。 |
| 努力提高和增加人民的收入。 | 努力提高人民的生活水平，增加收入。 |

### B7 主謂/修飾語配搭不當

| 病 | 修 |
| :--- | :--- |
| 他的性格非常美麗。 | 他的性格非常開朗。 |
| 工作效率十分龐大。 | 工作效率非常高。 |
| 寫作水準有了明顯的改進。 | 寫作水準有了明顯的提高。 |
| 懷著一顆忐忑不安的心情。 | 懷著忐忑不安的心。 |
| 他性格隨便友善。 | 他性格隨和友善。（「隨便」帶貶義，配「友善」錯位） |
| 幸好老師延遲課業的遞交限期，我們才能更充裕地完成家課。 | ……我們才有更充裕的時間完成家課。（「充裕」修時間，不修動作） |

### B8 語序不當

多層定語約按「領屬→指示→數量→動詞短語→形容詞→性質」；多層狀語約按「目的→時間→處所→範圍→情態→對象」。

| 病 | 修 |
| :--- | :--- |
| 一萬年前新出土的天然標本。 | 新出土的一萬年前的天然標本。 |
| 我在學校昨天看見了老師。 | 我昨天在學校看見了老師。 |
| 我們把這件事不告訴他。 | 我們不把這件事告訴他。 |
| 表決通過並認真討論了規劃。 | 認真討論並表決通過了規劃。 |
| 這首歌是今年這位歌手發表的作品。 | 這位歌手今年發表了這首歌。 |
| 這個農村糧食的生產，長期不能自給。 | 這個農村生產的糧食，長期不能自給。（定語掛錯中心語） |

關聯詞配對錯：雖然/而且、因為/而是等跨類搭錯——「雖然今天天氣很好，而且我們去郊遊」→「因為今天天氣很好，所以我們去郊遊」。

### B9 句式雜糅

兩種句式焊在一起，拆回一種：

| 雜糅 | 拆法 |
| :--- | :--- |
| 主要原因是……造成的 | 主要原因是……/是由……造成的 |
| 原因是因為…… | 原因是……/是因為…… |
| 是由於努力的結果 | 是由於努力/是努力的結果 |
| 大多是以……為主 | 大多是……/以……為主 |
| 旨在以……為目的 | 旨在……/以……為目的 |
| 是為了……的目的 | 是為了……/目的是…… |
| 成分是由……配製而成 | 成分是……/由……配製而成 |
| 有……等七個大項組成 | 包括……等七個大項/由……組成 |
| 需要非……不可 | 需要……/非……不可 |
| 主要目的，是為了…… | 主要目的是……（保留「主要」的程度義）/旨在……（較正式）——兩者語氣不同，按文類選，不是唯一正解 |

### B10 一面對兩面

「能否/好壞/與否」（兩面）對「關鍵保證/根本保障」（單向）失衡。兩邊同面：……

❌ 質量能否提高，是學校走向一流的關鍵保證。→ 兩邊同用「能否」，或兩邊都單向。
❌ 道德的好壞，關鍵在於樹立崇高理想。→ ……關鍵在於能否樹立崇高理想。

### B11 多重否定翻車

防止、避免、切忌、為免、警示已含否定，後面不再加「不」。

❌ 為了防止事故不再重演。→ ✅ 為了防止事故再次重演。
❌ 切忌不可使用明火。→ ✅ 切忌使用明火。
❌ 為免公眾不再產生誤解。→ ✅ 為免公眾產生誤解。

### B12 歧義

| 病 | 兩解 |
| :--- | :--- |
| 三個學校的優秀教師 | 三所學校的教師/學校的三位教師 |
| 局長囑咐小王下午一點半前去開會 | 一點半之前前往/一點三十分出發 |
| 他喜歡理髮和老師 | 喜歡「理髮與老師」兩者/喜歡「理髮師」 |

按實際意思重寫；拿不準就保留並提問。

## C 官腔、套話與模糊標籤

### C1 填充動詞與空洞結構

| 病 | 修 |
| :--- | :--- |
| 存在著許多困難。 | 有許多困難。 |
| 落實各項工作。 | 執行工作。 |
| 推進項目發展。 | 開展項目。 |
| 搭建交流平台。 | 創造交流機會。 |
| 打造新品牌。 | 創立新品牌。 |

「落實法律規定」「優化」（有明確技術定義時）保留。

極端副詞硬套：「嚴重同意」「高度肯定」「極度不滿」——「嚴重/高度/極度」同語義相撞（嚴重只配壞事）。按實際配搭改：一致贊成（「對方案嚴重同意」→「委員會一致贊成方案」）、深表關注、強烈不滿。

### C2 偽新詞

持份者（stakeholder）→按實際身分：學校師生、家長代表、業界同人。釋出善意→示好。「持份者」已是讀者熟悉的通用詞時可保留。

### C3 物理與工業術語濫用

語言高度濃縮→凝練；形勢出現變數→形勢有變；產生寒蟬效應屬固定概念保留；法律的「程序」屬法規術語保留。

### C4 委婉語

優化人手/縮減規模→裁員；資源增值→減薪或加工作量；待業→失業。**邊界**：公告可能刻意委婉，僅在用戶要求直言或語境明確時揭穿；不要擅自把官方通告改成指控。

### C5 口號與告示直譯

| 病 | 修 |
| :--- | :--- |
| 向毒品說不！ | 遠離毒品！ |
| 我們準備好了！ | 一切就緒！ |
| 狗隻不准進入。 | 請勿攜犬入內。 |
| 牽引你的大型狗隻。 | 大犬須以牽帶牽引。 |
| 為夢想創造可能。 | 助你實現夢想。 |

告示對象錯亂（把狗當受話人）改回面向人。用戶刻意選用的標語保留。

### C6 模糊標籤與網絡語

情商低、內耗、拉胯、emo、破防、yyds——抽象標籤沒有畫面。改寫方法：先理清實際行為（做了什麼、如何影響他人與工作）、前後因果、影響，再重寫成可觀察的描述：

❌ 小明情商低，時常內耗，工作能力很拉胯。
✅ 小明不善於察覺他人感受，開會常打斷同事；遇到難題又反覆自我懷疑，遲遲難以決定，交付因而屢有延誤。

概括用「不善於 X」比「不太能 X」順口；「作出決定」屬 A1 弱動詞：「難以及時作出決定」→「難以及時決定」。

不添加具體職業或事件（原意內含的具體化可以）。「不擅溝通、不善社交、內向」仍是半抽象標籤——概括句可留一句，但必須落一行為支撐：說了什麼、做了什麼、別人如何反應、對工作造成什麼。社交媒體語體且用戶刻意時保留。

## D 地域與語體判斷

### 香港預設

未指定地域時直接按香港讀者、香港語境、香港繁體書面語處理。香港慣用詞示例：屋苑、升降機、查詢、登記、質素、樓宇、巴士、的士、方便（形容詞用法）。這些是正確用語，不是要被「修正」的錯誤。

### 口語與書面

香港書面語 ≠ 粵語口語轉錄。「唔、嘅、咗、喎、係咁先」只在用戶明確要求港式口語、對話或社交媒體語氣時使用；原文刻意採用口語時保留其聲音。

### 北方口語入文

「咋辦、腦袋瓜子、啥、搞快點」等北方口語入通用書面語時改書面語：如何處理、頭腦靈敏、什麼、抓緊時間。

### 字形與用字

- 香港繁體用「著」不用「着」：拿著、沿著、看著、執著。遇「着」改「著」（引用原文或技術內容除外）。
- 「裡/裏」：香港書面語兩者皆見，跟隨原文或全文一致性，不強行統一。

### 不動清單

- Markdown 結構一字不動：標題層級（#、##）、列表、表格、連結、圍欄代碼；只潤正文文字，不動結構記號。
- 引文、作品名稱、標語、引用資料：正文可修，引用本身不動。
- 代碼、指令、URL、變數名、API、版本號：一字不動。
- 品牌、產品名、技術縮寫：保留大小寫。
- 日期、數字、貨幣、單位：依原格式，只在全文不一致或誤讀時統一。
- 法律、醫療、政策術語與條文語體：跟官方或原文既有寫法。
- 良性歐化：全球化、綠化、軟著陸等無地道替代的詞。
- 刻意風格：對話、廣告、文學、詩歌的口吻、節奏、修辭、刻意不規則。

### 輸出與提示

預設只回修訂稿。對話尚未建立地域或語體偏好時，修訂稿之後加一句非阻塞提示：「如需台灣、內地、澳門、新加坡、馬來西亞中文，或粵語口語/港式口語，可隨時指定。」用戶要求只回傳修訂稿、不要說明，或已指定偏好時，省略。
