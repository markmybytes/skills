## A 歐化句式（翻譯腔）

中文靠動詞推進，英文靠名詞與虛詞搭建。

- 歐化中文不是一律要除：余光中認為善用歐化可使中文活潑；「全球化」「綠化」等詞無地道替代，屬有益歐化。
- 要除的是「生澀的翻譯腔」——遮蔽動作、拖慢節奏、堆砌虛詞。

### A1 弱動詞+名詞化（義肢動詞）

「進行/作出/予以/加以/實施/展開」+雙音節動詞，把及物動詞降格為抽象名詞。中文的力氣在動詞，這類結構把引擎拆走，句子失去動感。

| 病 | 修 |
| :--- | :--- |
| 委員會就經貿問題進行了緊急商討。 | 委員會緊急商討經貿問題。 |
| 院方已向病患家屬作出了正式的道歉。 | 院方已向病患家屬正式道歉。 |
| 警方對嫌疑人實施了逮捕。 | 警方逮捕了嫌疑人。 |
| 這部機器需要技術人員進行定期的維護。 | 這部機器需要技術人員定期維護。 |
| 他對告誡沒有作出任何理會。 | 他對告誡毫不理會。 |

- 例外：「會議正在進行」「作出裁決」（公文體例）、「予以」有特定語氣時，可保留。

### A2 「的」字連環

英文關係子句直譯成前置定語，「的」字成災。

| 病 | 修 |
| :--- | :--- |
| 那隻白色的鴨在有不潔的顏色的都市的河溝裡叫。 | 那隻白鴨在都市骯髒的河溝裡叫。 |
| 這是一個很難被大眾所理解的非常複雜的社會現象。 | 這個社會現象極其複雜，大眾殊難理解。 |
| 他拿出了一本封面泛黃的記載著家族歷史的珍貴的族譜。 | 他拿出一本珍貴的族譜，封面泛黃，載有家族歷史。 |

### A3 大帽子句（長定語前置）

修飾子句整捆塞入名詞之前，頭重腳輕。先給主幹，再後置補充。

| 病 | 修 |
| :--- | :--- |
| 這是一座擁有超過五百年歷史同時完整保存了明清兩代建築風貌的古老宅院。 | 這座宅院歷史逾五百年，完整保存了明清兩代的建築風貌。 |
| 我想到了一條可以徹底解決目前財政赤字危機並安撫市場情緒的絕妙計策。 | 我想到了一條妙計，既可化解財政赤字，又能安撫市場情緒。 |
| 這個涉及開支約10億的建議可讓70萬人受惠。 | 這個建議涉及開支約10億，可讓70萬人受惠。 |

- 例外：法律、專利、產品規格依賴前置定語界定範圍時，保留固定結構。

### A4 濫用「被」

中文「被」傳統多含不如意、受損。中性或正面事態改主動、「獲/受/當選/應邀」，或無主句。

| 病 | 修 |
| :--- | :--- |
| 鋼琴家昨晚被邀請出席晚會。 | 鋼琴家昨晚獲邀出席晚會。 |
| 茶水已經被喝光了。 | 茶水已經喝光了。 |
| 這項提議被董事會廣泛接受。 | 董事會普遍贊同這項提議。 |
| 這部著作被廣大讀者熱烈歡迎。 | 這部著作深受讀者歡迎。 |

- 「獲」本身已含承受義；「被人們廣泛接受」的「被人們」是贅餘。

### A5 濫用「一個」

英文冠詞直譯。真要計數時才用。

- 家朗是一個小五學生 → 家朗是小五學生
- 這是一個很難理解的問題 → 這個問題很難理解

### A6 萬能連詞

and 見句必插，破壞中文並列節奏。

| 病 | 修 |
| :--- | :--- |
| 大會檢討了過去的工作，以及展望了未來，並通過了決議。 | 大會檢討過去，展望未來，通過決議。 |

- 例外：「及/和/以及」連接兩個動作短語（「專心上課和認真複習」）時常屬自然；連詞承載真實邏輯關係（轉折、條件）時保留。

### A7 代詞與所有格堆砌

中文承前省略是常態；英文的 his/it/they 照抄則生澀。

| 病 | 修 |
| :--- | :--- |
| 母親看著她的兒子，眼中充滿了她的關愛。 | 母親凝望著兒子，眼中滿溢關愛。 |
| 當張先生見到他的朋友時，他對他說…… | 張先生見到朋友，說…… |

- 指涉可能混淆時（「他告訴小明，他明天會提交報告」）補回「自己」或名詞，以清楚為準。

### A8 「……之一」

one of the... 直譯，削弱判斷句態。

| 病 | 修 |
| :--- | :--- |
| 這是當前治理面臨的最棘手的難題之一。 | 這是當前治理極為棘手的難題。 |

- 邊界例（保留）：「香港是全球三大藝術品交易中心之一」——「三大」名單可考，屬合法「之一」。（真實公報句）

### A9 介詞外框

關於、對於、在……上/方面、作為、透過……來……

| 病 | 修 |
| :--- | :--- |
| 關於他的申請，委員會今天進行了審查。 | 委員會今天審查了他的申請。 |
| 歡迎李教授今天來到我們的中間。 | 歡迎李教授今天蒞臨。 |
| 透過進行系統升級來改善登入體驗。 | 透過系統升級改善登入體驗。 |
| 對於這些不禮貌的行為，我不能不質疑。 | 這些不禮貌的行為，我不能不質疑。（話題可作賓語直陳時刪框；「就」較輕，「對於」較重） |

- 「透過/以」表達真實手段關係且語域合適時可保留，不必為避詞而改。

### A10 「當……的時候」

余光中：「當當之聲不絕於耳」。時間關係清楚時刪。

| 病 | 修 |
| :--- | :--- |
| 當我走到十字路口的時候，紅燈亮了。 | 我剛走到十字路口，紅燈正好亮起。 |
| 當問題被發現的時候，我們將會立即地進行處理。 | 發現問題後，我們會立即處理。 |

- 需要明確限定時間界線或法律通知時點時，保留必要標記。

### A11 「們」字成災

- 「桌子們」→「桌子」
- 集體名詞（聽眾、觀眾、群眾）本身已表複數
- 「小鳥們」→「群鳥」
- 註：此病主要見於翻譯稿；香港本地原創文本少見。

### A12 抽象名詞後綴

-ability/-ness/-ization 直譯。

| 病 | 修 |
| :--- | :--- |
| 他的言論帶有強烈的侮辱性。 | 他的話極其無禮。 |
| 體操動作的難度非常大。 | 體操動作極難。 |

### A13 機械「地」

-ly 直譯。中文有疊字、擬聲、文言副詞。

| 病 | 修 |
| :--- | :--- |
| 他冷漠地注視著匆忙地走過的行人。 | 他漠然注視著匆匆而過的行人。 |

- 「持續地密切關注」→「密切留意」類的疊加尤須清理。
- 註：此病主要見於翻譯稿；香港本地原創文本少見。

### A14 模糊程度詞

「某程度上」同屬此類。

- 真句（政府文本）：「政府會在相關情況下，以適當方式作出跟進。」——「適當方式」空泛程度語，實際處置為何隻字不提。
- 原文刻意含糊且屬正式表述時可保留。

### A15 時態硬譯

「他曾經去過」視語境可留「曾/過」之一。

- 註：此病主要見於翻譯稿；香港本地原創文本少見。

### A16 長句無逗點

中文靠逗號呼吸。超長句先找主謂賓，按邏輯斷句：

❌ 他甚至沒有因為這樁慘案而傷心得使他在法庭宣判那天無法維持一個專業律師應有的冷靜與為當事人爭取權益的決心。
✅ 遭逢這樁慘案，他固然傷痛，但在法庭宣判當天，仍維持了律師應有的冷靜，決心為當事人爭取權益。

### A17 存在句虛主詞

there be 句式直譯：「有……的原因/情況/可能」托住空洞尾詞，重心被拖到句尾。把重心移前，讓真主語當家。

| 病 | 修 |
| :--- | :--- |
| 這個方案有值得商榷的地方。 | 這個方案值得商榷。 |

- 「有」表真實存在（「桌上有一本書」）不屬此類。
- 邊界例（保留）：「目前已經有超過100間科技企業及機構簽約進駐」——「有」帶可數名單，真實存在，合法。（真實公報句）

## B 病句

### B1 主語殘缺（介詞吞主語）

| 病 | 修 |
| :--- | :--- |
| 在老師的悉心教導下，讓我明白了樂趣。 | 老師的悉心教導，讓我明白了樂趣。 |
| 從大量的考古實物觀測中，證實了歷史的真實性。 | 大量的考古實物，證實了歷史的真實性。 |

### B2 暗中換主語

| 病 | 修 |
| :--- | :--- |
| 這名小選手一舉奪金，受到了組委會的通報嘉獎。 | 這名小選手一舉奪金，組委會對其予以通報嘉獎。（或：……並獲組委會通報嘉獎。） |
| 海洋公園咬傷訓練員的十二歲雌性海獅，經過一星期隔離監察後，今日恢復表演，順利完成。 | ……今日恢復表演，表演順利完成。（「完成」的主體是表演，不是海獅；真實新聞句） |
| 政府提早發放信息，傳媒全面報道，並且一直很廣泛地傳播資訊，發揮了重要作用。 | ……傳媒全面報道並廣泛傳播資訊，發揮了重要作用。（「發揮」的主體要指明是誰） |

### B3 謂語殘缺

| 病 | 修 |
| :--- | :--- |
| 這種高粱不僅畝產量極高，而且比進口高粱更強的抗旱能力。 | ……而且比進口高粱具有更強的抗旱能力。 |
| 全體員工積極為公司的未來發展。 | 全體員工積極為公司的未來發展而奮鬥。 |

### B4 賓語殘缺

| 病 | 修 |
| :--- | :--- |
| 這部劇成功塑造了幾位熱血抗日青年的故事。 | 這部劇成功塑造了幾位熱血抗日的青年形象。 |

### B5 同義重複

- 高達……之巨
- 聞名遐邇的海內外
- 真知灼見的意見
- 由衷地在心裡感謝
- 歷歷在目地出現在眼前
- 責無旁貸的責任
- 重複再做
- 「心裡感到非常不勝榮幸」→「不勝榮幸」（「不勝」本身即「非常」，三重疊）

各刪冗餘一半。

### B6 動賓配搭不當

| 病 | 修 |
| :--- | :--- |
| 好朋友應互相分擔快樂和憂愁。 | 好朋友應互相分享快樂，分擔憂愁。 |
| 努力提高和增加人民的收入。 | 努力提高人民的生活水平，增加收入。 |

### B7 主謂/修飾語配搭不當

| 病 | 修 |
| :--- | :--- |
| 他的性格非常美麗。 | 他的性格非常開朗。 |
| 工作效率十分龐大。 | 工作效率非常高。 |
| 寫作水準有了明顯的改進。 | 寫作水準有了明顯的提高。 |
| 懷著一顆忐忑不安的心情。 | 懷著忐忑不安的心。 |

### B8 語序不當

- 多層定語約按「領屬→指示→數量→動詞短語→形容詞→性質」。
- 多層狀語約按「目的→時間→處所→範圍→情態→對象」。

| 病 | 修 |
| :--- | :--- |
| 我在學校昨天看見了老師。 | 我昨天在學校看見了老師。 |
| 我們把這件事不告訴他。 | 我們不把這件事告訴他。 |
| 這個農村糧食的生產，長期不能自給。 | 這個農村生產的糧食，長期不能自給。（定語掛錯中心語） |

### B9 句式雜糅

兩種句式焊在一起，拆回一種：

| 雜糅 | 拆法 |
| :--- | :--- |
| 主要原因是……造成的 | 主要原因是……/是由……造成的 |
| 原因是因為…… | 原因是……/是因為…… |
| 是由於努力的結果 | 是由於努力/是努力的結果 |
| 大多是以……為主 | 大多是……/以……為主 |
| 旨在以……為目的 | 旨在……/以……為目的 |
| 是為了……的目的 | 是為了……/目的是…… |
| 成分是由……配製而成 | 成分是……/由……配製而成 |
| 有……等七個大項組成 | 包括……等七個大項/由……組成 |
| 需要非……不可 | 需要……/非……不可 |
| 主要目的，是為了…… | 主要目的是……/旨在…… |

### B10 一面對兩面

「能否/好壞/與否」（兩面）對「關鍵保證/根本保障」（單向）失衡。兩邊同面：……

❌ 道德的好壞，關鍵在於樹立崇高理想。→ ……關鍵在於能否樹立崇高理想。

### B11 多重否定翻車

防止、避免、切忌、為免、警示已含否定，後面不再加「不」。

❌ 為了防止事故不再重演。→ ✅ 為了防止事故再次重演。
❌ 切忌不可使用明火。→ ✅ 切忌使用明火。

### B12 歧義

| 病 | 兩解 |
| :--- | :--- |
| 局長囑咐小王下午一點半前去開會 | 一點半之前前往/一點三十分出發 |
| 他喜歡理髮和老師 | 喜歡「理髮與老師」兩者/喜歡「理髮師」 |

## C 官腔、套話與模糊標籤

### C1 填充動詞與空洞結構

| 病 | 修 |
| :--- | :--- |
| 落實各項工作。 | 執行工作。 |
| 搭建交流平台。 | 創造交流機會。 |
| 打造新品牌。 | 創立新品牌。 |

- 「優化」（有明確技術定義時）保留。

### C2 偽新詞

- 釋出善意 → 示好
- 「一站式平台」→按實際：單一窗口／全程一站處理（one-stop 直譯；真實公報詞）
- 「優化校本學習活動支援津貼」——政策名詞堆疊示範（真實津貼名；引用官方名稱時不動）

### C3 物理與工業術語濫用

- 形勢出現變數→形勢有變
- 「全面準備，廣泛和深化部署，把破壞降低。」→按實際：充分準備、適時調整，減低破壞。（工程/軍事語域滑入民生；真實官員原句）
- 「部署航班安排」→「編排航班」。（「部署」由軍事語域濫入行政）

### C4 委婉語

- 待業→失業；縮減規模→裁員
- 「適當跟進」——萬用委婉詞，常掩蓋具體處置；公告刻意委婉時不揭穿（邊界見 SKILL C4）。（真實公文通用）
- 「不良營商手法」——執法委婉術語，按語境保留或具體化。（真實官員原句）

### C5 口號與告示直譯

| 病 | 修 |
| :--- | :--- |
| 狗隻不准進入。 | 請勿攜犬入內。 |
| 牽引你的大型狗隻。 | 大犬須以牽帶牽引。 |
| 為夢想創造可能。 | 助你實現夢想。 |

- 告示對象錯亂（把狗當受話人）改回面向人。
- 真實告示語料（語域參考，非病句）：
  - 「受檢人士如有病徵，應立即求醫，按照醫護人員的指示接受檢測，不應前往流動採樣站及社區檢測中心。」（指令堆疊長句）
  - 「家長無須回覆中學是否接受有關自行分配學位。」（標準「無須……是否」結構）

### C6 模糊標籤與網絡語

情商低、內耗、拉胯、emo、破防、yyds——抽象標籤沒有畫面。

- 原文有行為/事例線索 → 按線索具體化，勿添新事實。
- 原文純標籤、沒有任何事實 → 不作故事，照交保守版本＋提問。

方法細節見 SKILL.md〈C6〉。

## 搭配自測（通用工具，不依賴語感）

背景：LLM 訓練資料被官腔公文污染（土地到位、全力推進、抓好落實、打造XX）。

- 「讀得順」的直覺本身可能已中毒——高頻錯搭配正是生成時機率最高的下一個詞。
- 所以搭配對錯不靠直覺，靠可執行的測試。
- 語言學基礎是 selectional preferences（動詞對論元的語義類型限制）：不必列搭配表，測類型兼容。語料庫研究（Chinese Word Usage Errors、OCCA 搭配資源）同樣以「搭配錯配＝語義不合」為判準。

兩類錯誤要分開：

- **類型錯誤**（土地落成、拉著鋼琴）——搭配自測可通用偵測，不必詞典。
- **語體錯誤**（打造、推進、到位、賦能）——搭配本身「通」，只是官腔；靠 C1 目錄逐個養，發現一個入一個。

三個測試（定義/pivot/畫面）的操作與例子見 SKILL.md〈搭配自測〉。

- 香港慣用詞（正確用語，勿「修正」）：屋苑、升降機、查詢、登記、質素、樓宇、巴士、的士、方便（形容詞用法）。
