# h730-toolbox

h730-toolbox (730 工具庫) is an internal web application for the House730 team, providing dashboards and tooling to support daily operations.

## Tech Stack

| Layer        | Technology                                           |
| ------------ | ---------------------------------------------------- |
| **Backend**  | Laravel 12 (PHP ^8.2) + Inertia.js v3                |
| **Frontend** | Vue 3 (Composition API) + TypeScript                 |
| **Styling**  | Tailwind CSS v4 + DaisyUI 5                          |
| **Database** | MySQL 8 (primary) + secondary House730 DB connection |

## Prerequisites

- PHP ^8.2 with [extensions required by Laravel](https://laravel.com/docs/12.x/deployment#server-requirements)
- [Volta](https://volta.sh) (manages Node version automatically)
- MySQL 8 running locally
- Composer

## Quick Start

```bash
# 1. Clone & configure
cp .env.example .env
# Edit .env: set DB_DATABASE, DB_USERNAME, DB_PASSWORD for your MySQL instance

# 2. Install dependencies
composer install
npm install

# 3. Bootstrap the app
php artisan key:generate
php artisan migrate:fresh --seed

# 4. Start development stack (server + queue + logs + Vite)
composer dev
```

### Seeded-data limits

- Dynamic ad seeders create database rows only. RSS/CSV/XML files are not generated by `db:seed`; downloads stay unavailable until House730 API credentials are configured and dynamic-ad file generation is run.
- Web Vitals seeders provide demo history rows for local navigation. Live refresh jobs still need `GOOGLE_API_KEY`.

## Commands

### Dev Server

| Command        | What it does                                             |
| -------------- | -------------------------------------------------------- |
| `composer dev` | Runs server, queue listener, logs, and Vite concurrently |

### Quality & Testing

Run **auto-fix** tools first, then **check** tools for remaining issues:

| Scope    | Auto-fix                             | Check                |
| -------- | ------------------------------------ | -------------------- |
| PHP      | `./vendor/bin/pint`                  | `composer test`      |
| Vue / TS | `npm run format && npm run lint:fix` | `npm run type-check` |
| Build    | —                                    | `npm run build`      |

### Standalone Commands

| Command                               | Purpose                                |
| ------------------------------------- | -------------------------------------- |
| `composer test`                       | Clears config, runs PHPUnit            |
| `npm run test`                        | Runs Vitest (JS tests)                 |
| `npm run build`                       | Production asset build                 |
| `npm run format:check`                | Check formatting (CI/pre-PR read-only) |
| `php artisan auth:make-admin <email>` | Promote a user to admin                |
| `php artisan dynamic-ad:restore {id}` / `--all` | Restore soft-deleted dynamic ad(s)    |

### Generated Files

For IDE autocomplete. Neither is a runtime file.

- `php artisan ziggy:generate --types-only` → `resources/js/ziggy.d.ts`. Type definitions for `route()` calls. Committed to git; CI checks freshness.
- `php artisan ide-helper:generate` → `_ide_helper.php`. Docblocks for facades, models, and helpers. Gitignored; auto-runs on `composer update` (via the `post-update-cmd` hook).
