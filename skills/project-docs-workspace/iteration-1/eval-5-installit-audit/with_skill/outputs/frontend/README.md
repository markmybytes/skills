# frontend — install-it UI

Vue 3 + TypeScript frontend for the install-it Wails desktop app. This is a
Wails-managed frontend, not a standalone Vite app: the Go backend bindings
under `wailsjs/` are generated by Wails.

## Development

Run from the repository root so the Wails runtime and generated bindings are
available:

```sh
wails dev
```

`npm run dev` alone starts Vite without the Wails bridge and will not work
standalone.

## Scripts

| Command              | Purpose                                   |
| -------------------- | ----------------------------------------- |
| `npm install`        | Install dependencies                      |
| `npm run dev`        | Vite dev server (use `wails dev` instead) |
| `npm run build`      | Production build + type-check             |
| `npm run type-check` | `vue-tsc` type-check                      |
| `npm run lint`       | ESLint                                    |
| `npm run format`     | Prettier (writes `src/`)                  |
| `npm test`           | Vitest unit tests (see `src/__tests__/`)  |
